# 当前迭代日志

## 目标

定义第一版首页、项目、画布、对话、技能和提示词模板的产品关系，为交互原型提供唯一的当前需求来源。

## 已完成

- 已创建独立产品定义分支 `product-definition-v1`。
- 已将两张用户参考图保存到 `docs/design/references/` 并记录参考边界。
- 已定义项目、画布、工作流、节点、对话、技能和提示词模板的统一术语。
- 已把首页导航、项目生命周期、画布工作区、技能与提示词模板拆成独立功能需求。
- 已明确对话位于画布右侧，以及底部节点栏、更多入口和右键新增节点的方向。
- 已确认首页右上角可直接新建空白画布，不再只有对话一种创建方式。
- 已确认底部一级入口为插入、裁切、生成；插入二级菜单包含文本、图片、视频。
- 已确认裁切模块用于把一个或多个规则图集批量拆成图片集合，支持单张缩放、移动和“仅当前/应用全部”；生成当前不接入模型。
- 已确认裁切结果可按横向或纵向顺序排列，该方向不代表裁切网格本身的行列形状。
- 已确认首版不提供预置提示词模板，顶部工具栏暂不设置按钮。
- 已确认产品定位为模块化个人效率工作台，画布是工作台的核心区域。
- 已确认底部常用模块栏、右键菜单和双击画布三种模块创建入口都需要保留。
- 已确认模块可以独立使用，只有需要交换内容或表达处理顺序的模块才提供连接端口。
- 已确认输入端口位于卡片左侧、输出端口位于右侧，模块可按功能具有多个具名端口并支持多条连接。
- 已确认功能模块需要统一的扩展边界，后续添加新模块不应重写画布核心。
- 已将未确认内容集中到开放问题，避免猜测进入正式需求。
