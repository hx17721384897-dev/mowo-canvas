# 项目概述

## 产品定位

MOWO Canvas 是一个节点与连线型无限画布工具。用户可以在可缩放、可平移的画布上创建内容节点、组织素材并表达节点之间的关系。

## 当前使用场景

- 单个用户在自己的 Windows 电脑上运行。
- 通过浏览器访问本机 Next.js 服务。
- 创建、编辑、保存和恢复多个画布项目。
- 管理文本、图片、视频等本地素材节点。

## 发展方向

先验证画布交互和本地数据可靠性，再逐步增加更丰富的节点、线上账户、国内云存储及可能的 AI 能力。未来方向不构成当前功能承诺，以 `02-product-scope.md` 为准。

## 成功标准

- 用户不需要技术知识即可创建和恢复画布。
- 程序重启后项目和素材保持完整。
- 数据可以备份、迁移和恢复。
- 核心前端在未来上线时不需要推倒重写。
