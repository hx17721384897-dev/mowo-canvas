# 资产与图片下载 V01

对应图片：`asset-download-v01.png`

## 状态

用户已于 2026-11-02 认可该视觉方向。

## 已确认表达

- 左侧顶部只提供“功能”和“资产”两个页签，资产页默认展示当前项目资产。
- 资产页提供搜索、添加、类型筛选以及图片、视频、文字资产的紧凑展示。
- 图片下载弹窗顶部为链接输入与下载按钮；首轮实现不接入 LINE 或其他平台的真实解析下载。
- 弹窗主体采用左侧大预览、右侧缩略图布局。
- 弹窗维持紧凑的左右平衡比例；素材在左侧预览窗口内等比完整显示，不随素材尺寸向弹窗其他区域溢出。
- 下载结果默认全选；取消勾选的缩略图降低颜色和视觉权重，但仍可恢复选择。
- 动图默认播放，并提供上一张、暂停/播放和下一张操作。
- 当前素材的 APNG 类型标识位于“已下载图片”标题旁，不覆盖预览或底部操作区。
- 弹窗底部提供取消与导入操作。

## 实现边界

- 图片中的猫狗素材仅用于说明布局，不进入正式用户数据或默认素材库。
- 文字资产改为用户手动保存，不因输入文字自动进入资产库。
- 真正的平台下载解析由后续适配器实现；未接入时界面必须明确提示，不能伪造下载结果。
