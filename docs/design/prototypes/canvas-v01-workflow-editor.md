# 画布 V01：工作流编辑器

## 目标

验证工作流编辑器的五区布局，以及完整工具库、常用工具、项目操作和 AI 对话之间的职责分工。

## 已确认方向

- 中央为无限画布。
- 左侧为服务当前工作流的完整工具库，不照搬首页导航。
- 顶部为类似文档软件的项目级工具栏，保存是其中的代表性操作。
- 底部为左侧工具库中高频功能的快捷入口。
- 右侧为当前项目对话面板，未来连接语言模型和生图模型。
- 生图结果未来直接成为画布上的图片模块。
- 模块输入端口位于左侧、输出端口位于右侧，并支持多端口和多连接。
- 裁切卡片当前只展示外壳、端口、占位按钮区与预览区，不代表真实裁切功能已经确定或实现。

## 图中仅为候选

- 左侧工具的分类、名称、图标和顺序。
- 顶部工具栏除保存外的具体操作。
- 底部默认显示哪些高频工具，以及是否允许用户自定义。
- 右侧对话栏宽度、折叠方式、模型选择器与输入区细节。
- 画布上的示例图片、连线数量和卡片尺寸。
- 裁切卡片内部所有按钮名称、顺序和行为。
- 颜色、圆角、阴影和最终品牌视觉。
