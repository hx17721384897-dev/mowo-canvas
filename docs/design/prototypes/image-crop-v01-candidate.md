# 图片裁切 V01 界面候选

- 状态：**当前最新设计，用户已确认；V01 已实现**。
- 日期：2026-11-06。
- 入口：已导入的图片节点工具栏「裁切」；已有有序组的播放预览中可进入「裁切编辑」。
- 本文只记录界面与交互候选，不替代当前画布需求或既有批量裁切卡片的实现状态。

## 1. 网格设置弹窗

```text
┌ 裁切图片 ─────────────────────────────────────────────── × ┐
│ 模板 [无模板 ▾] [新建模板] [管理模板]                     │
│                                                          │
│ ┌ 原图预览 · 可缩放/平移视图 ───────┐ ┌ 网格 1 ─────────┐ │
│ │  ┌─ 可移动、可缩放的网格 ─────┐   │ │ 行 [2] 列 [2]    │ │
│ │  │ 可拖动的横纵分割线         │   │ │ X/Y [ ] [ ]      │ │
│ │  └────────────────────────────┘   │ │ 宽/高 [ ] [ ]    │ │
│ └───────────────────────────────────┘ │ 比例 3:2         │ │
│ [重置当前网格] 原图 1145×1374 px      └──────────────────┘ │
│ 网格列表 [网格1 2×2] [+ 添加网格] · 总计 4 张              │
│ 输出 [原样 / 固定比例] [裁切 / 补透明边] · 像素尺寸预览    │
│                                      [取消] [创建裁切预览] │
└──────────────────────────────────────────────────────────┘
```

默认网格覆盖原图；输入行列后初始等分，分割线可拖。特殊布局用多个网格，例如第一排 `1×3`、第二排 `1×2`，网格外不输出。拖网格调整位置；方向键以原图像素微调，按住 ⇧ 加速；按住 ⇧ 拖角锁定当前网格比例。数值输入为原图坐标，不随预览缩放改变。模板可保存网格布局与导出规格，但不自动覆盖已编辑的当前方案。没有横向线、纵向线、删除线按钮。

2026-11-07 更新：原图置于独立深色视口中央，四周留出可滚动、可拖动的操作空间，网格继续外移时工作区自动扩展。按住 Ctrl 滚轮围绕指针缩放工作区，也可用按钮缩放或居中原图。网格可超出原图边界，超出部分预览和生成时为透明；缩放和平移只改变编辑视图，不改变网格的原图像素坐标或输出尺寸。

2026-11-07 补充：首次打开时原图按左侧视口的可用宽高尽量铺满显示；滚动条隐藏，可继续用拖动和 Ctrl+滚轮浏览。网格平移与拖角时靠近原图左右/上下边缘、中心或其他网格的边缘和中心，会按约 8 个屏幕像素吸附；吸附期间出现对应的虚线参考线，松手消失。网格超出原图的能力保留。

2026-11-07 尺寸规则更新：新方案用「固定单格尺寸」控制输出。启用后首网格的单格宽高成为所有网格的共用像素尺寸；网格各自保留行列数和位置，调整单格宽高或拖动网格右下角会同步全部网格。分割线等距，启用时若需改动既有不等距布局会提示。关闭时各张按自己的实际裁切框尺寸输出，允许不等距分割。可添加和删除网格，最后一个网格不能删除。单格宽高比可输入（例如 1:1、3:2），设定后宽高联动；固定模式影响全部网格，自由模式影响当前网格。手动移动分割线会解除当前网格的比例锁定。新方案始终保留画面，原图外部分补透明，不提供等比铺满裁掉选项。旧裁切草稿仍按其保存时的输出规则渲染；重新调整网格后采用新规则。

2026-11-07 界面更新：开关显示为「固定比例」，紧接比例预设、可编辑比例和网格宽高。通用比例预设为「无」「自由比例」「1:1」「16:9」「4:3」「3:2」「9:16」；手动改动预设比例后变为「自由比例」。勾选时同步全部网格的单格比例和尺寸，行列与位置仍独立；未勾选时只修改当前网格。微信表情规格不预置，未来由用户自建模板。新增模板表单可填写名称、行列、单格宽高、可选比例和是否全局固定，也可保存当前全部网格布局；保存模板不立即替换当前方案。裁切弹窗内 Ctrl+Z/撤销按钮恢复布局操作，拖动按一次操作记录，输入框仍用原生文字撤销。

## 2. 画布上的裁切结果卡片

```text
原图 ────→ ┌ 裁切结果 · 5 张预览 ───────────────────┐
           │ [设为有序组 ○] [播放预览] [重新设置网格] │
           │ [01 图] [02 图] [03 图] [04 图] [05 图]│
           │ 每张图：预览 · 编辑                     │
           │ 预览顺序：网格列表顺序，再逐行逐列       │
           │ 状态：未生成素材                        │
           │                    [生成图片]           │
           └────────────────────────────────────────┘
```

「创建裁切预览」只写入原图引用、网格、输出规格和每张调整参数；预览按需渲染，不写正式图片资产。卡片单独连接在原图下游。勾选「设为有序组」仅记录生成意图、顺序和可选帧时长；实际有序组要求正式静态资产，必须到「生成图片」时才创建。未勾选则生成普通图片集合。生成后保留结果卡片的来源与参数；再次修改并生成新版本，不覆盖旧资产。草稿阶段不提供下载。

## 3. 单张调整窗口

```text
┌ 调整第 02 / 05 张 ───────────────────────────────────── × ┐
│ ┌ 当前预览 ┐  ┌ 调整后 · 可拖画面 ┐  ┌ 参数 ────────────┐ │
│ │          │  │ 输出画框固定      │  │ 缩放 110%         │ │
│ │          │  │ 超出范围真实显示  │  │ X/Y 偏移  +5% ... │ │
│ └──────────┘  └───────────────────┘  │ 居中 / 恢复原样   │ │
│ [上一张] [播放/暂停] [下一张]          └──────────────────┘ │
│ [预览时间轴] 当前位置 / 总张数 · 当前张状态                  │
│                         [取消] [应用到其他 ▾] [保存调整]    │
└───────────────────────────────────────────────────────────┘
```

切换帧或播放使用当前内存中的调整预览，便于检查抖动；普通裁切结果也能播放，但预览顺序不等同有序组语义。播放、上一张/下一张共用既有逐帧查看的计时与导航逻辑，裁切控件仅在此窗口出现。应用到其他的弹层列出同批次其余图片及全选，先预览后确认；应用本次缩放倍率与按输出画框宽高归一化的位移增量，保留目标图已有调整。当前图片默认保存。关闭有未保存调整时提示保留或放弃。

## 4. 已有有序组的入口

已有有序组「播放预览」增加「裁切编辑」。进入同一单张调整窗口时，各帧以完整原图为初始范围，不显示图集网格设置。保存调整形成新的派生方案；生成时创建新的图片资产与有序组，原有序组不被覆盖。普通有序组单纯播放时不出现移动或裁切控件。

## 逻辑复盘与边界

1. **预览不是正式裁切**：单张「保存调整」只更新方案；结果卡片「生成图片」才创建正式资产。关闭方案不影响原图。
2. **草稿有序意图不等于现有有序组**：生成前不伪造需要正式图片成员的组节点。
3. **新方案不拉伸画面**：固定单格尺寸时所有结果采用相同的原图像素范围；自由模式逐张保留裁切框的实际尺寸。原图外的区域补透明像素。
4. **越过初始网格**：预览真实呈现可能露出的相邻内容并提示；未来橡皮/画笔是每张结果的独立修饰层，当前版本不伪装为已擦除。
5. **既有批量裁切卡片**：保持当前占位，不与图片快捷入口同时实现两套裁切规则。以后复用同一裁切方案与生成逻辑，批量卡片只负责多来源编排。
6. **撤销与资产**：预览方案及参数修改可撤销；正式生成后的资产保留来源链，画布撤销只撤掉放置，不删除文件。
