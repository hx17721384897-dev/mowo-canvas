# 首页 V01：画布项目中心

## 目标

验证首页从“对话创建任务”改为“浏览、新建和进入画布项目”的信息架构。

## 已确认方向

- 首页不设置 ChatGPT 式大型对话框。
- 主体展示历史画布项目卡片。
- 页面提供清晰的“新建画布”入口。
- 首页导航与进入项目后的工作流工具库不是同一套侧栏。
- 设置区域需要为以后管理模型 API 提供入口。

## 图中仅为候选

- 项目卡片的缩略图、标签、时间与更多菜单。
- 搜索、排序以及虚线新建卡片是否同时保留。
- 首页侧栏的准确宽度、图标与折叠方式。
- 颜色、圆角、阴影和最终品牌视觉。
