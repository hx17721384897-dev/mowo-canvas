# 动图拆帧 V01 原型

## 原型文件

- [画布节点与序列帧组](animated-frame-extraction-v01-canvas.png)
- [逐帧查看窗口](animated-frame-extraction-v01-viewer.png)

## 表达目标

- 多个动图图片模块可以连接到同一个“动图拆帧”模块。
- 每个拆帧结果使用第一帧封面与后方多层错位图片重影表达序列帧集合，不使用文件夹图标。
- 结果整体拖入画布后形成真正的组，帧图片从左到右、从上到下按顺序排列。
- 逐帧查看窗口提供上一组、下一组、动画播放、当前帧、逐帧切换、时间信息和整组放入画布。

## 评审边界

- 原型用于确认信息结构、视觉层级和主要操作，不代表最终像素尺寸。
- 图中的 4×3 仅演示 12 帧排列；实际组使用自适应网格，默认列数仍需在实现前确定。
- 第一版格式范围为 APNG、GIF，动态 WebP 延后。
- 原型中的“打开资产位置”和单帧下载是否进入第一版，可在功能实现前进一步确认。
