# 视频拆帧节点 V01

状态：2026-11-18 当前有效，按素材类型处理、超限后选择。

1. 初始展示连接的视频、勾选和各自的「动画／拍摄视频」互斥按钮。连接仅读大小、时长，不分析帧数；不符合60秒/200MiB限制时提示并提供「进入编辑页裁剪」。引用片段按自身范围在执行时检查实际大小。
2. 符合输入限制即可点击「生成图片组」。动画分析连续重复画面并按比例还原帧位，保留一拍二、一拍三；拍摄视频保留源帧，不自动合并或抽帧。依据不足时在卡片输入目标帧率并确认继续。
3. 处理结果不超过150张直接在旁边生成原有批次组/有序子组，不要求额外准备或确认。
4. 结果超过150张则显示实际数量及「仅输出前150帧」「抽帧」「进入编辑页裁剪」。抽帧展开唯一一处N/K设置，实时显示数量；超过150时不能确认抽帧。用户主动选择前150帧才截断尾部。
5. 待确认状态持久保存在原任务，确认后继续同一批次；批量内已完成的结果保持。重复生成请求、确认、恢复与刷新不新增同次结果。

卡片正文可拖动，选择、输入和按钮不触发拖动。截图已由隔离浏览器更新，展示242帧视频超限后选择每2帧取1帧、得到121张的状态。
