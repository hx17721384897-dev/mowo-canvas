# 视觉参考说明

本目录保存用户提供的产品截图，只用于帮助理解布局和交互关系。截图中的功能不会自动成为 MOWO Canvas 的需求，正式范围以需求文档为准。

## `reference-home-lovart.png`

可参考：左侧导航、首页大型对话入口、模板分类入口、下方内容卡片的层级关系。

不可直接继承：原产品品牌、Logo、新建项目按钮的具体形式、素材、个人主页、设计委托、账户、积分、生图工具和其他未确认入口。

## `reference-canvas-lovart.png`

可参考：对话与画布并列、顶部工具区、底部浮动工具栏及大面积画布空间。

MOWO 差异：对话面板必须位于右侧；底部主要承载节点创建；工作流以可连接节点为核心；第一版不提供图片生成、分享、会员或积分能力。

## 使用规则

1. 原型可以借鉴信息层级，不逐像素复制界面。
2. 任何从截图推导的新功能都必须先进入开放问题，用户确认后才能写成正式需求。
3. 当用户确认新的视觉版本后，替换当前参考或依靠 Git 回到此前干净版本，不在主文档反复引用已放弃设计。
