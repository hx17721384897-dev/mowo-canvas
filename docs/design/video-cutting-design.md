# 视频片段剪辑设计书

> 2026-11-17 已确认的交互方向。产品验收以[视频编辑 PRD](../requirements/features/video-editor.md#视频片段剪辑分阶段实施中)为准。画面裁切与构图属于下一阶段。

## 用户流程与坐标

用户从原片的观察页进入，下方编辑区起初只有一段完整原片。用户在编辑区拆分、修剪、删除、重排片段，按成片顺序预览，最后分别选择「下载 MP4」或「保存到素材库并放入画布」。原片和自动/人工分镜始终保持原来的源帧顺序。剪辑工程按项目和原片自动保存，成片交付只读取已保存的工程版本。

上方源帧时间轴的坐标是原片显示帧序号；下方编辑区的坐标是成片累计时长。编辑片段以稳定 ID、来源资产 ID、半开源帧范围 `[inFrame,outFrame)` 和排列顺序表示。每段的成片时长由源帧 PTS 边界计算，不用平均帧率推测可变帧率视频。成片时间定位先找到覆盖该时间的编辑片段，再映射到该片段的源 PTS 和源帧。相同源帧被重复使用时，以当前编辑片段 ID 区分映射。

例如原片分镜 A=0–99、B=100–199、C=200–299。将 B 修剪为 120–179，再把 C 移到 B 前面，下方显示 A→C→B(120–179)；上方仍显示 A→B→C。选中 B 时上方只标记实际使用的 120–179，原分镜 B 的 100、200 边界不改变。成片从 C 切到 B 时，上方源播放头从约 299 跳到 120，成片播放头继续向前。

## 页面交互

| 操作 | 片段选择 | 预览框与播放头 | 上方源帧时间轴 |
| --- | --- | --- | --- |
| 点击片段条 | 只选中该片段 | 保持当前画面和位置 | 标出该段引用的源帧范围；不定位 |
| 点击片段条上方或下方的空白时间区域 | 保持选择 | 定位成片时间，显示成片预览 | 定位到该成片位置对应的原片帧 |
| 点击上方源帧时间轴 | 保持编辑片段 | 进入明确标识的「查看原片」状态，显示所选源帧 | 按原片帧定位，可查看未用于成片的画面 |
| 在「查看原片」状态点击播放 | 保持编辑片段 | 从所选源帧沿原片顺序播放 | 上方播放头跟随；下方成片播放头保持原位 |
| 播放成片 | 由正在播放的片段确定映射 | 按下方顺序连续播放 | 随当前源帧移动，在片段边界可以跳跃 |
| 拖动片段主体 | 选中被拖动片段 | 拖动期间保持当前预览画面 | 原分镜位置不变 |

拖动主体时在下方显示跟随片段的预览和目标插入线/空位，放下后才改变顺序。拖动左右边缘修剪时间范围，与主体移动的命中区域分开。修剪可跨越分镜切点，靠近切点可吸附。删除编辑片段只移出成片。上方用选中片段的源范围标记和源播放头说明来源，不增设整条重排后的分镜时间轴。

上方原有观察缩放和平移保持观察含义。源帧时间轴下方的颜色说明文字移除。下方编辑区需要足够高度，和上方源帧时间轴共享可调整的底部工作区。预览框明确显示「成片预览」或「查看原片」，避免把已删除的源画面误认作成片。

撤销与重做分别有常驻按钮，共用按时间顺序排列的编辑历史，覆盖人工分镜校正与成片片段操作。执行新操作后清空重做分支。撤销/重做失败不得移动历史指针；输入框中的文字撤销仍由输入框处理。原片、分镜结果和已保存的旧片段资产不得被剪辑历史直接改写。

## 实施进度目标

| 步骤 | 目标与交付 | 验收 |
| --- | --- | --- |
| 1 页面骨架与定位 | 下方编辑区显示完整原片；点击片段只选中，点击上下空白时间区域才定位；去掉颜色说明并调整工作区高度 | 选中不跳帧；空白定位使画面与上方源帧同步；索引准备前仍可粗定位；现有分镜和手动选区可用 |
| 2 成片数据与双时间坐标 | 建立片段序列和成片→源帧映射；选中源范围标记、原片/成片预览状态 | 删除或重排后的源帧映射正确；重复引用同一源段时定位无歧义 |
| 3 剪辑操作 | 拆分、修剪、删除、拖动重排及插入预览；成片连续播放 | 拖动与修剪区域明确；跨切点修剪与吸附正确；无片段、末帧及切换边界可预览 |
| 4 编辑历史与保存 | 两个常驻按钮，分镜及剪辑共享撤销/重做；工程持久保存与恢复 | 跨两类操作按顺序撤销/重做；刷新恢复；失败不丢失已保存工程 |
| 5 结果交付 | 依据已确认的保存/导出/回画布规则完成媒体渲染、校验和资产关联 | 导出顺序、帧范围、音视频同步正确；失败不生成正式半成品；原片不变 |

步骤 1 至 5 构成片段剪辑的完整交付路线。画面裁切、视频相对固定画布移动和输出画面缩放在上述流程完成后单独设计。

## 当前进度

步骤 1 已接入：下方显示一条完整原片，点击片段只选中，点击上下空白区域定位；移除了源帧时间轴颜色说明，并增加了底部默认高度。1280×800 隔离浏览器验证编辑区可见、选中不跳帧、空白定位后源帧同步。

步骤 2 已接入：片段以稳定 ID 与源帧半开区间表示；成片时间与原片 PTS 之间建立映射，按选中片段标出上方源帧范围，预览框标明「成片预览」或「查看原片」。重排与重复使用同一源范围的纯模型测试通过；隔离浏览器验证源范围标记、点击上方查看原片、点击下方空白处回到成片预览。

步骤 3 已接入：在播放头拆分所选片段，拖动片段两端修剪、拖动主体重排并显示插入线和跟随预览，可删除片段；删除全部后可重新加入完整原片。修剪边界接近分镜切点时吸附，源分镜顺序与边界保持不变。成片按编辑顺序播放，跨片段与原片结尾可继续切换，空成片不可播放。片段编辑模型测试、隔离浏览器拆分/重排/插入预览/跨段续播/删除/修剪及原视频入口回归通过。

步骤 4 已接入：页面顶部常驻独立「撤销」「重做」按钮，按成功操作的先后顺序覆盖分镜校正和剪辑片段修改；新操作清空重做分支，校正提交失败不前移历史。剪辑工程按项目和原片自动保存到单行记录，500 ms 防抖并串行提交，带版本冲突校验；保存失败保留页面内容并可重试，重新打开恢复已保存的顺序和边界。刷新会清空本页操作历史。隔离浏览器验证跨两类操作撤销/重做及刷新恢复，API 验证无效范围和旧版本拒绝，数据库验证反复保存只有一条工程、剪辑未额外产生选区草稿。下一步为步骤 5：根据确认的交付规则渲染与导出成片。

步骤 5 已接入：用户选择的两种交付分别为直接下载 MP4，或生成正式视频资产并在当前画布放入一张视频卡片。渲染按每段精确源帧范围和排列顺序连接画面与音轨，输出原片画幅的 H.264/AAC MP4；没有音轨的来源保持无音轨。完成后核对输出帧数、时长与音轨，校验失败不创建正式资产。下载只使用临时文件；入库按工程版本和内容哈希去重，重复操作不产生重复成片或画布卡片，也不创建选区草稿。带音频三色片段实测绿→红→蓝顺序、10 帧及音轨同步通过；隔离接口和浏览器验收通过。接下来进入实际素材验收，随后讨论固定输出画布和画面裁切、移动、缩放。

2026-11-18 可用性重做：用户指出原有色块编辑区无法实际使用。依据[Concat 界面和源码对照](video-cutting-concat-reference.md)，下方改为带时间尺、稀疏源帧缩略画面、缩放、横向滚动和明确修剪把手的单轨编辑区；拖动换序显示目标空位及跟随预览。适应全片随窗口宽度重新计算，跨片后活动片段与成片时间码按实际源时间同步。301 秒隔离浏览器样本验证缩略画面加载、缩放与适应全片、拆分、真实指针拖动换序、跨片续播、删除和边缘修剪；撤销/重做、刷新恢复、下载、入库及回画布回归通过。仍需用户用实际素材验收操作手感与画面顺序。

播放边界修复：预览播放按钮遵循当前预览模式。上方源帧定位后继续播放原片，下方成片播放头冻结；下方定位后继续播放成片。成片末尾暂停并回显最后保留帧，下次播放从成片开头重启。5 帧裁剪片段在 301 秒隔离视频中的浏览器回归通过，类型检查和定向 ESLint 通过；真实素材仍待用户验收。

连续接缝和末帧修复：相邻片段引用的源帧首尾连续时直接切换活动片段，不再给视频元素重复设置同一时间；播放中的成片指针使用连续更新的成片时钟，避免在边界映射暂时为空时回退。末段在下一源帧呈现前暂停，并保持源视频在最后保留帧的末段时间内，不再回拨到该帧起点。隔离浏览器验证连续接缝无媒体 seek、成片播放头不倒退、末尾源位置不回拨，以及原片/成片重播模式；真实素材仍需验收。
