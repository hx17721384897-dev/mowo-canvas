# AI 运行接口草案

状态为阶段 0 设计草案，尚未实现。业务规则以 [Agent 计划](../ai/agent-implementation-plan.md) 为准。

## 创建与查询

POST /api/projects/{projectId}/ai/runs 接收 clientRequestId、用户消息与配置 ID，服务端组装历史并保存输入快照。成功创建返回 202 与 runId、状态查询及事件订阅地址。会话 ID 与客户端 ID 唯一；重复同输入返回原运行，已完成返回 200，同 ID 不同输入返回 409。

GET /api/projects/{projectId}/ai/runs?clientRequestId=... 查询尚未取得 runId 的请求；GET /api/ai/runs/{runId} 返回持久状态、消息及最后事件序号。前端先恢复运行，再决定是否新建。

## 订阅与停止

GET /api/ai/runs/{runId}/events?after={sequence} 使用 SSE 订阅持久事件，支持状态、文本增量、用量与错误。事件按序号去重。重连时返回快照与后续事件的无缺口交接，终态必须查询确认。浏览器断线只结束订阅。

POST /api/ai/runs/{runId}/stop 幂等请求停止，返回当前状态或停止中。后台执行器读取停止意图并取消上游。停止与成功竞争同一原子状态转换，已提交终态保持稳定。

## 执行与限制

Next.js 请求只负责创建、查询与订阅，独立本地执行器持有供应商请求并持久保存输出。运行领取与写入校验执行租约；过期执行实例无法覆盖新状态。进程退出后核对并标记无法续接的运行。

请求错误区分参数、配置、鉴权、余额、限流、网络及供应商错误。接口不返回密钥或原始认证头。本地单用户阶段仍校验项目、会话及配置归属。并发、消息长度与超时数值在验证后锁定。

## 待验证

必须验证重复提交、断线前后查询、停止竞态、运行重启、事件重放和归属校验。当前尚未运行这些端到端检查。
