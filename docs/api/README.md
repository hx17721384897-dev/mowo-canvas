# API 文档入口

当前业务接口：

- `assets.md`：本地资产查询、图片导入、跨项目引用与内容读取。

## 每个接口必须记录

- 用途与调用方
- 方法和路径，或 Server Action 名称
- 请求参数、类型、必填项和大小限制
- 成功响应与状态码
- 可预期错误、错误码和用户提示
- 身份、权限和数据范围
- 幂等性、并发与重试行为
- 对应实现、类型和验证方式

## 规则

- 代码与文档在同一变更中更新。
- 服务端必须重新验证客户端输入。
- 错误响应不泄露密钥、文件系统路径或内部堆栈。
- 未稳定的内部接口不伪装成公开兼容承诺。
- 如果未来形成对外 HTTP API，再创建并维护 OpenAPI 文件；现在不生成空规范。
