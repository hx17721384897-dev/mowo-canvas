# 产品范围

## 第一版当前范围

- 可折叠左侧导航：首页、项目、技能。
- 最近项目入口与首页历史项目区域。
- 首页对话创建入口与提示词模板入口。
- 发送首条消息时创建项目，并通过动画进入画布。
- 第一版采用“一项目一画布”，项目关联工作流和对话。
- 画布位于主体区域，对话面板位于右侧。
- 无限画布：平移、缩放、选择、拖动。
- 文本和图片节点方向，以及节点连线。
- 底部常用节点栏、更多节点入口和右键新增节点菜单。
- 顶部画布工具区，具体按钮待确认。
- 技能列表与管理入口，具体编辑深度待确认。
- 本地保存节点、连线、视口、项目对话和必要的技能配置。
- 自动保存与明确的保存状态。
- 项目 JSON 导入、导出。
- 本地素材引用与预览。
- 撤销、重做和基础快捷键。
- 本地备份与恢复。
- 项目列表的打开、重命名和删除。

## 当前明确不做

- AI 生图、AI 视频或模型调用。
- DeepSeek 或其他在线 AI 对话 API。
- 注册、登录、找回密码和第三方登录。
- 多人实时协作。
- 订阅、付费和订单。
- 公网部署、域名、备案和 CDN。
- 微信、短信、邮件通知。
- Kubernetes、微服务和分布式队列。
- Figma/Photoshop 式自由矢量绘制。
- 参考产品中的素材、个人主页、设计委托、积分和分享等未确认模块。

## 范围变更规则

新增功能必须先判断属于当前阶段还是未来阶段。若改变产品边界，先更新本文件与路线图，再实现代码。临时实验不改变本文件；只有用户确认纳入主线后才更新。
