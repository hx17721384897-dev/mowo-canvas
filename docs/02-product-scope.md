# 产品范围

## 第一版当前范围

- 可折叠左侧导航：首页、项目、技能。
- 首页以历史画布项目为主体，并提供清晰的“新建画布”入口。
- 首页不设置 ChatGPT 式大型对话输入框；点击历史画布进入对应项目。
- 第一版采用“一项目一画布”，项目关联工作流和对话。
- 工作流编辑器不沿用首页侧栏：左侧为完整工具库，顶部为项目级工具栏，底部为常用工具快捷栏，右侧为当前项目对话。
- 编辑器采用紧凑字体与控件密度，中央画布优先占用空间；左右侧栏均可折叠。
- 无限画布：平移、缩放、选择、拖动。
- 底部一级入口：插入、裁切、生成；插入二级菜单包含文本、图片、视频。
- 裁切点击后直接建立批量裁切卡片；首个原型只做外壳、左右端口和按钮区域。完整裁切目标是把一个或多个规则图集拆成图片集合，并支持单张缩放、移动和应用到全部结果；生成节点不接入模型。
- 更多节点入口、右键新增节点菜单和节点连线。
- 模块支持四种创建入口：左侧完整工具库、底部常用工具栏、画布空白处右键菜单、双击画布快捷创建。
- 模块可以独立使用；只有需要传递内容或处理顺序的模块才提供连接端口。
- 模块输入端口位于左侧、输出端口位于右侧；支持多个具名端口，以及按端口规则进行单连接或多连接。
- 为后续功能卡片保留统一扩展边界，但第一版不建设第三方插件安装系统。
- 不提供预置提示词模板。
- 设置与右侧助手进入已认可的 AI 接入迭代，具体范围与验收见下节。
- 技能列表与管理入口，具体编辑深度待确认。
- 本地保存节点、连线、视口、项目对话和必要的技能配置。
- 自动保存与明确的保存状态。
- 项目 JSON 导入、导出。
- 本地素材引用与预览。
- B 站视频下载精简首版已完成扫码、单 P/画质选择、单任务下载、手动重试、确认入库、兼容预览与交付收尾，待用户体验验收。高级恢复与批量能力为可选后续迭代，见[下载 PRD](requirements/features/video-download.md)。
- 视频观察与分镜之后增加片段剪辑：在源帧时间轴下方编辑成片的拆分、修剪、删除和顺序，联动原片帧查看；分镜校正与剪辑共用独立的撤销、重做按钮。画面裁切、移动和输出画面缩放放在剪辑完成后的下一阶段。见[视频编辑 PRD](requirements/features/video-editor.md#视频片段剪辑分阶段实施中)。
- 撤销、重做和基础快捷键。
- 本地备份与恢复。
- 项目列表的打开、重命名和删除。

## 当前明确不做

- AI 视频生成。
- 通过 Skill 自动操作画布，等待后续 V5 迭代。
- 注册、登录、找回密码和第三方登录。
- 多人实时协作。
- 订阅、付费和订单。
- 公网部署、域名、备案和 CDN。
- 微信、短信、邮件通知。
- Kubernetes、微服务和分布式队列。
- Figma/Photoshop 式自由矢量绘制。
- 参考产品中的素材、个人主页、设计委托、积分和分享等未确认模块。

## 已认可的 AI 接入迭代

V1 基础对话已接入。正式模型设置和密钥存储仍属 V1 后续工作，当前范围见[设置与模型需求](requirements/features/settings-and-models.md)。V2 图像生成及后续阶段的范围和进入条件见 [AI 长期路线](ai/agent-implementation-plan.md)。

@ 资产引用、联网搜索和 Skill 分别安排在 V3、V4、V5。当前进入准备阶段，已认可范围与已实现能力需分别记录。

- 右侧项目对话可调用用户在设置中配置的语言模型或生图模型。
- 生图结果直接作为图片模块进入当前画布。
- API 密钥不得进入前端代码、公开环境变量或 Git。

## 范围变更规则

新增功能必须先判断属于当前阶段还是未来阶段。若改变产品边界，先更新本文件与路线图，再实现代码。临时实验不改变本文件；只有用户确认纳入主线后才更新。
