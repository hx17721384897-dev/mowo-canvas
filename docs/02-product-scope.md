# 产品范围

## 当前范围

- 本地项目列表：创建、打开、重命名、删除项目。
- 无限画布：平移、缩放、框选、拖动。
- 基础节点：文本、图片、视频。
- 节点连线、删除和复制。
- 保存节点、连线和视口位置。
- 自动保存与明确的保存状态。
- 项目 JSON 导入、导出。
- 本地素材引用与预览。
- 撤销、重做和基础快捷键。
- 本地备份与恢复。

## 当前明确不做

- AI 生图、AI 视频或模型调用。
- 注册、登录、找回密码和第三方登录。
- 多人实时协作。
- 订阅、付费和订单。
- 公网部署、域名、备案和 CDN。
- 微信、短信、邮件通知。
- Kubernetes、微服务和分布式队列。
- Figma/Photoshop 式自由矢量绘制。

## 范围变更规则

新增功能必须先判断属于当前阶段还是未来阶段。若改变产品边界，先更新本文件与路线图，再实现代码。临时实验不改变本文件；只有用户确认纳入主线后才更新。
