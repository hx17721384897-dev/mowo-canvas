# 本地部署

## 当前目标

在单台 Windows 电脑上运行，通过 `localhost` 访问，不向公网开放端口。

## 预计运行方式

开发模式：

```text
npm run dev
```

稳定本地运行：

```text
npm run build
npm run start
```

包管理器与最终命令在项目脚手架创建后确认并更新。本文现在不代表依赖已经安装。

## 本地数据

- SQLite 数据库和素材目录不进入 Git。
- 程序升级不得覆盖 `data`。
- 数据目录位置应可配置，不能散落在源代码目录中。
- 仅复制程序代码不等于完成数据备份。

## 安全边界

- 默认只监听本机需要的接口。
- 不通过路由器端口映射、内网穿透或公网 IP 暴露开发服务。
- 环境变量和密钥不得提交 Git。
- 若后续允许局域网访问，应先重新评估认证、权限和防火墙。

Docker、开机启动器和桌面封装延后到本地功能稳定后评估。
