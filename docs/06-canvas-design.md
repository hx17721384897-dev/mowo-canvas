# 画布设计

## 交互模型

画布由节点、连线和视口组成。所谓无限画布是通过视口的 `x`、`y`、`zoom` 变换实现，不创建无限尺寸的 DOM。

项目页采用以画布为中心的五区布局：中央为无限画布，左侧为功能与资产面板，顶部为项目级全局工具栏，底部为常用工具快捷栏，右侧为当前项目的 AI 对话面板。编辑器左侧不沿用首页导航。

左侧顶部提供“功能”和“资产”两个一级页签。“功能”承载完整工具库；“资产”承载文字、图片和视频资产，并允许把已从画布移除的资产再次拖回画布。提示词库页签当前不制作。

中央画布拥有最高面积优先级。编辑器使用比 V01 样品图更紧凑的字体、行高和控件间距；左侧工具库与右侧对话面板都可独立折叠，折叠后空间立即归还画布。两侧面板与画布相邻的边缘提供可拖拽分隔条，用户可以在限定范围内调整面板宽度；拖拽过程中画布实时获得或让出空间。

整个项目页称为工作台，画布是工作台的核心区域。用户界面使用“模块”和“连接”；实现层使用 React Flow 的节点和连线模型。

## 节点入口

- 左侧工具库：组织当前工作流的完整功能模块，例如下载、筛选及以后新增的处理工具。
- 底部常用工具栏：依次提供移动/选择、撤销、重做、整理占位、文本、图片、视频、音频和组；素材入口直接创建节点。
- 裁切：一级入口，点击后直接创建批量裁切卡片；用户在卡片内选择网格数量与排列方式。
- 生成：一级入口，当前创建节点形态但不接入模型或产生生成结果。
- 更多：为以后增加的节点类型预留入口。
- 双击：在画布空白处提供快捷创建入口。

## 顶部工具栏

顶部工具栏类似文档编辑软件的全局操作区，用于保存等项目级能力。它不承担完整模块库职责，具体按钮清单在原型评审中确认。

## 右侧对话与模型产物

- 右侧对话只属于当前项目。
- 首个原型只制作对话结构，不调用语言模型或生图模型。
- 未来接入生图模型后，生成图片直接成为当前画布上的图片模块，并沿用普通图片模块的移动、连接、保存与恢复规则。

## 基础操作

- 鼠标或触控板平移、缩放。
- 单选、框选和多选节点。
- 拖动节点。
- 从 Handle 创建连线。
- 删除、复制节点和连线。
- 撤销、重做。
- 适应视图与回到默认视图。
- 从底部常用节点栏或“更多节点”入口创建节点。
- 在画布空白处右键，通过菜单在点击位置附近创建节点。
- 双击画布空白处，通过快捷创建入口添加模块。

## 行为规则

- 节点位置、尺寸和业务数据必须可序列化。
- 节点组件不直接读取本地文件系统或数据库。
- 素材节点只保存 `assetId`，由数据层解析素材。
- 图片素材节点在画布上直接呈现完整图片；通用卡片标题只用于功能模块。图片被选中时显示悬浮操作栏和等比例缩放控制点，未选中时保持内容优先。
- 普通图片节点不得在图片侧面常驻文件名、尺寸、格式或状态信息卡。未选中时只呈现图片内容；选中时只增加悬浮工具栏、选中边框、缩放控制点、左右连接点和轻量“图片”标识。详细信息通过悬浮工具栏中的信息入口按需打开。
- 文本、图片、视频和音频素材节点均提供左侧输入与右侧输出连接点；连接点在悬停或选中时出现。
- 空图片节点可从本地导入；文件先进入项目资产库，节点只保存返回的资产引用。
- 组使用 React Flow 父子节点关系；从资产区直接拖入组或把画布节点拖入组后保存 `parentId`，不复制资产文件。
- 删除引用资产的模块实例只移除当前画布上的放置，不删除资产；从资产区再次拖入时创建新的模块实例。
- 文本输入时，画布快捷键不得干扰正常输入。
- 删除等破坏性操作必须支持撤销，或在不可撤销时二次确认。
- 自定义节点使用稳定组件引用并关注重渲染性能。
- 节点、连线和视口通过项目画布文档防抖保存；顶部保存按钮触发立即保存，离开页面时补交未保存状态。
- 模块默认可以独立使用；只有存在明确输入或输出的模块才显示端口。
- 输入端口统一位于卡片左侧，输出端口统一位于卡片右侧，不使用底部端口。
- 一个模块可以有多个具名输入或输出端口，以表达不同内容类型；例如未来的拼接模块可以分别提供图片输入与文字输入。
- 端口需要声明可接收的内容类型以及单条或多条连接规则；连接时只允许兼容内容进入。
- 支持多连接的输入端口可以汇集多个上游来源，输出端口也可以连接多个下游模块。

## 分组交互

### 布局组

布局组只负责空间整理，不代表资产或集合，因此不显示数据端口。用户可以通过以下方式创建：

- 未选择节点时点击底部“组”，创建一个空虚线框。
- 选择两个及以上同层节点后，悬浮工具栏显示“创建组”；底部“组”与 `Ctrl + G` 执行同一操作。
- `Ctrl + Shift + G` 在选中布局组时解除分组，保留内部节点。

节点拖入布局组时使用中心点判断。节点中心进入组框内边缘 12px 后，组框高亮并提示“松开加入组”；只有边缘重叠不算加入。释放后如果节点尺寸超出组框，组框自动扩大到完整容纳节点。节点中心越过组框外边缘 24px 后显示“松开移出组”，释放后解除父子关系并保持节点在画布上的绝对位置。选中组内节点时也提供“移出组”按钮，作为不依赖拖动的稳定入口。

点击组框边线或标题栏选中布局组；拖动标题栏移动整个组及其子节点。组的悬浮工具栏提供重命名、适应内容、折叠/展开、解除分组、删除和更多操作。解除分组只移除容器；删除组及内部画布实例必须支持撤销，且不删除被引用资产。

### 带数据语义的结果组

序列帧组和批量结果组既承担布局，也代表有类型的数据，因此可以显示端口。序列帧组输出一个有序图片集合；批量结果组接收处理模块输出，并可以向支持批处理的下游模块输出多个序列帧集合。端口固定在组标题栏左右两侧，展开和收起时不移动，避免连接线跳动。

普通布局组不能因为内容恰好都是图片就自动获得端口；需要传递数据时应显式创建或转换为有类型的集合组。

### 批量结果组与序列帧组

动图拆帧的外层批量结果组使用比普通布局组更大的虚线框，顶部显示组数、总帧数和保存状态。内部序列帧组折叠时以第一帧封面、多层错位重影、来源名称、当前帧数和保存状态呈现。

第一版一次只允许展开一个序列帧组。多个折叠小组排列在顶部，共用下方序列编辑区；选择另一个小组时复用同一编辑区，不先收起外层组，也不改变其整体高度。展开区显示真实帧节点，支持选择、多选、调整顺序、从序列移除和保存最终序列。

首次展开时，编辑区在约 180ms 内由上向下揭开并淡入；如果超出视口，只平移画布使其可见，不自动改变缩放。切换小组时，旧内容约 80ms 淡出，新内容轻微上移 8px 并在约 120ms 内淡入；收起时编辑区在约 180ms 内缩回。系统启用减少动态效果时取消位移并缩短或关闭动画。

拖动已展开的序列帧组时，拖动预览临时折叠为堆叠封面；释放后在新位置恢复原展开状态。从序列帧组拖出单帧默认执行“复制到画布”，不改变原序列；需要修改序列时使用明确的“从序列移除”。

## 批量裁切模块

以下描述是完整产品目标。首个原型只制作卡片外壳、左右端口、按钮占位区和预览占位区，不执行裁切，也不提前确定具体按钮。

- 用途：把一张包含多格内容的图集拆分为多张独立图片，例如把 16 格表情图拆成 16 张表情图片。
- 输入：可以接收一张或多张来源图片；多个图片模块可以连接到同一裁切模块进行批量处理。
- 布局：用户在卡片内部选择 16 张、20 张等裁切类型；精确的预设行列组合仍待确认。
- 结果顺序：裁切后的图片支持按横向顺序或纵向顺序排列。这里的方向描述结果排列与浏览顺序，不表示裁切网格本身的行列形状。
- 校正：裁切后可以选中某一结果，在固定裁切框内对内容进行缩放和移动。
- 应用范围：用户可以选择只把校正应用到当前结果，或应用到本次裁切的全部结果。
- 输出：裁切结果以图片集合进行批量输出，并保留集合内单张图片可被独立处理的能力。

## 功能模块扩展边界

画布核心不能把每一种功能卡片写死。每个功能模块需要能够独立声明自己的名称、类别、输入端口、输出端口、可配置项和卡片主体；新增模块时不应重写画布的连接规则。首版只建设项目内的模块注册边界，不建设第三方插件市场或动态安装系统。

处理结果如果需要持久保存、再次查看、拖入画布或继续连接，必须进入独立结果模块。处理模块卡片保持紧凑，只保留运行入口、必要设置、状态和错误摘要；进度等临时信息留在处理模块，序列帧集合等可复用数据留在结果模块。

“动图拆帧”输出一个批量结果组，其中每个来源动图对应一个序列帧组。折叠序列帧组以第一帧封面和后方多层错位重影表达有序图片集合，不使用文件夹图标；打开其中一组进入共用序列编辑区或逐帧查看，拖出其中一组可在画布上独立放置。

## 暂不覆盖

真实 AI 生成功能、自由画笔、复杂矢量路径、时间轴剪辑、多人光标和实时冲突合并不属于首批画布能力。“生成”节点当前只是预留卡片，不代表已接入 AI。
