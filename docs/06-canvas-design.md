# 画布设计

## 交互模型

画布由节点、连线和视口组成。所谓无限画布是通过视口的 `x`、`y`、`zoom` 变换实现，不创建无限尺寸的 DOM。

第一版项目页采用“画布主体 + 右侧对话面板”的布局。画布顶部放置全局工具，底部放置常用节点入口。

## 节点范围

- 文本节点：标题与正文。
- 图片节点：引用本地图片素材并预览。
- 裁切节点和视频节点是否进入第一版尚未确认，不得提前视为正式范围。

## 基础操作

- 鼠标或触控板平移、缩放。
- 单选、框选和多选节点。
- 拖动节点。
- 从 Handle 创建连线。
- 删除、复制节点和连线。
- 撤销、重做。
- 适应视图与回到默认视图。
- 从底部常用节点栏或“更多节点”入口创建节点。
- 在画布空白处右键，通过菜单在点击位置附近创建节点。

## 行为规则

- 节点位置、尺寸和业务数据必须可序列化。
- 节点组件不直接读取本地文件系统或数据库。
- 素材节点只保存 `assetId`，由数据层解析素材。
- 文本输入时，画布快捷键不得干扰正常输入。
- 删除等破坏性操作必须支持撤销，或在不可撤销时二次确认。
- 自定义节点使用稳定组件引用并关注重渲染性能。

## 暂不覆盖

AI 生成节点、自由画笔、复杂矢量路径、时间轴剪辑、多人光标和实时冲突合并不属于首批画布能力。
