# 画布设计

## 交互模型

画布由节点、连线和视口组成。所谓无限画布是通过视口的 `x`、`y`、`zoom` 变换实现，不创建无限尺寸的 DOM。

项目页采用以画布为中心的五区布局：中央为无限画布，左侧为功能与资产面板，顶部为项目级全局工具栏，底部为常用工具快捷栏，右侧为当前项目的 AI 对话面板。编辑器左侧不沿用首页导航。

左侧顶部提供“功能”和“资产”两个一级页签。“功能”承载完整工具库；“资产”承载文字、图片和视频资产，并允许把已从画布移除的资产再次拖回画布。提示词库页签当前不制作。

中央画布拥有最高面积优先级。编辑器使用比 V01 样品图更紧凑的字体、行高和控件间距；左侧工具库与右侧对话面板都可独立折叠，折叠后空间立即归还画布。两侧面板与画布相邻的边缘提供可拖拽分隔条，用户可以在限定范围内调整面板宽度；拖拽过程中画布实时获得或让出空间。

整个项目页称为工作台，画布是工作台的核心区域。用户界面使用“模块”和“连接”；实现层使用 React Flow 的节点和连线模型。

## 节点入口

浮出菜单打开时，父项与菜单之间保留鼠标通道。通道和菜单优先接收鼠标事件，分割线的其他位置仍可拖动调整宽度。鼠标离开父项和菜单后延迟约 150 毫秒关闭，移回时取消关闭。此规则适用于「下载」和「动图处理」。

左侧「功能」中，带子项的导航沿用「输出 → 下载」样式：父项右侧显示箭头，鼠标悬停或键盘聚焦时在右侧浮出子菜单。子项统一使用图标、名称和简短说明。「处理 → 动图处理」依次提供「动图拆帧」「动画帧编辑」。从侧栏创建的编辑节点等待接入动画帧批次或单个帧序列，批次下方的快捷入口自动连线。动画帧拼接上线后再加入该菜单。

- 左侧工具库：组织当前工作流的完整功能模块，例如下载、筛选及以后新增的处理工具。
- 底部常用工具栏：依次提供移动/选择、撤销、重做、整理占位、文本、图片、视频、音频和组；素材入口直接创建节点。
- 底栏图片入口创建空图片节点；节点上传支持一次选多张并直接放入画布，文件同时加入当前项目资产。单张填入该节点；多张纯数字文件名，或相同前缀加数字后缀的文件，按数字组成有序组；其他文件分开排列，达到 8 张时自动放入普通无序组。
- 裁切：一级入口，点击后直接创建批量裁切卡片；用户在卡片内选择网格数量与排列方式。
- 生成：一级入口，当前创建节点形态但不接入模型或产生生成结果。
- 更多：为以后增加的节点类型预留入口。
- 双击：在画布空白处提供快捷创建入口。

## 顶部工具栏

顶部工具栏类似文档编辑软件的全局操作区，用于保存等项目级能力。它不承担完整模块库职责，具体按钮清单在原型评审中确认。

## 右侧对话与模型产物

- 右侧对话只属于当前项目。
- 首个原型只制作对话结构，不调用语言模型或生图模型。
- 未来接入生图模型后，生成图片直接成为当前画布上的图片模块，并沿用普通图片模块的移动、连接、保存与恢复规则。

## 基础操作

- 鼠标或触控板平移、缩放。
- 单选、框选和多选节点。
- 拖动节点。
- 从 Handle 创建连线。
- 删除、复制节点和连线。
- 撤销、重做。
- 画布获得操作焦点时，Ctrl+Z 执行底栏撤销；Ctrl+X 将选中的可复制节点写入画布剪贴板后从画布移除，相关连线一并移除，资产保留。剪切可一次撤销。输入框和弹窗保留原生快捷键。
- 适应视图与回到默认视图。
- 从底部常用节点栏或“更多节点”入口创建节点。
- 在画布空白处右键，通过菜单在点击位置附近创建节点。
- 双击画布空白处，通过快捷创建入口添加模块。

## 行为规则

- 节点位置、尺寸和业务数据必须可序列化。
- 节点组件不直接读取本地文件系统或数据库。
- 素材节点只保存 `assetId`，由数据层解析素材。
- 图片素材节点在画布上直接呈现完整图片；通用卡片标题只用于功能模块。图片被选中时显示悬浮操作栏和等比例缩放控制点，未选中时保持内容优先。
- Ctrl 多选两张及以上图片后，拖动任一图片角点会以该图片的尺寸变化比例同步缩放其他选中图片；每张图片维持自己的宽高比和位置。任一图片的最短边达到 80 画布像素后不能继续缩小。单图缩放保持原行为。
- 普通图片节点不得在图片侧面常驻文件名、尺寸、格式或状态信息卡。选中时显示悬浮工具栏、选中边框和缩放控制点。图片节点左上角标识的显示规则见 [REQ-CANVAS-018](requirements/features/canvas-workspace.md#req-canvas-018-图片直接呈现)。详细信息通过悬浮工具栏中的信息入口按需打开。
- 文本、图片、视频和音频素材节点均提供左侧输入与右侧输出连接点；连接点在悬停或选中时出现。
- 空图片节点可从本地导入；文件先进入项目资产库，节点只保存返回的资产引用。
- 组使用 React Flow 父子节点关系；从资产区直接拖入组或把画布节点拖入组后保存 `parentId`，不复制资产文件。
- 删除引用资产的模块实例只移除当前画布上的放置，不删除资产；从资产区再次拖入时创建新的模块实例。
- 手动有序组采用自动网格布局和插入排序；具体交互及静态图片检查见 [动画帧需求](requirements/features/animated-frame-extraction.md)。
- 普通组和有序组的卡片工具可导出 ZIP。名称在导出弹窗中按次修改；有序组文件按组内顺序编号，普通组保留素材原名，重名追加后缀，嵌套组对应子目录。详见[画布需求](requirements/features/canvas-workspace.md#普通组与有序组导出)。
- 文本输入时，画布快捷键不得干扰正常输入。
- 删除等破坏性操作必须支持撤销，或在不可撤销时二次确认。
- 自定义节点使用稳定组件引用并关注重渲染性能。
- 节点、连线和视口采用[串行保存与浏览器草稿恢复](05-data-design.md#保存策略)。
- 模块默认可以独立使用；只有存在明确输入或输出的模块才显示端口。
- 输入端口统一位于卡片左侧，输出端口统一位于卡片右侧，不使用底部端口。
- 一个模块可以有多个具名输入或输出端口，以表达不同内容类型；例如未来的拼接模块可以分别提供图片输入与文字输入。
- 端口需要声明可接收的内容类型以及单条或多条连接规则；连接时只允许兼容内容进入。
- 支持多连接的输入端口可以汇集多个上游来源，输出端口也可以连接多个下游模块。
- 移动和选择模式均支持从左右端口拖线。拖动时显示贝塞尔虚线，接到兼容端口后显示实线。空白处松开时提供兼容节点菜单，选中后创建节点并自动连线，可一次撤销。
- 按住 `Ctrl` 临时切换移动和选择模式，松开恢复。移动模式可点选节点，拖动画布空白处平移。`Shift` 用于多选。缩放范围为 5%–200%。
- 在项目资产列表单击图片可放到当前视口中央，连续放置沿右下以约 24 屏幕像素错开。拖拽按落点放置。「画布上的资产」筛选下，单击定位已有节点。
- 悬停节点高亮一层直接相连的节点和线。点选线时单独高亮该线，按 Delete 或 Backspace 删除关系。空白菜单可通过 Esc 或点击菜单外取消。

## 分组交互

### 布局组

布局组提供右侧「组内素材」输出端口。连接拆帧节点时读取当前成员，布局组本身不创建资产集合。用户可以通过以下方式创建：

选中组可折叠为堆叠封面卡，并在当前位置展开。组内布局和尺寸保留，内部连线随内容隐藏，跨组连线临时显示在封面边缘。多选同层组后可合并成员或套入外层虚线框。合并会将组输出改为合并后的成员范围，已有组输出连线时先提示。折叠、展开、合并和嵌套支持撤销，并尊重系统减少动态效果设置。

- 未选择节点时点击底部“组”，创建一个空虚线框。
- 选择两个及以上同层节点后，悬浮工具栏显示“创建组”；底部“组”与 `Ctrl + G` 执行同一操作。
- `Ctrl + Shift + G` 在选中布局组时解除分组，保留内部节点。

单独拖动节点或子组时，超过其面积的一半进入组框才高亮并可松手入组。已入组的节点或子组拉出过半时，原组取消高亮，松手后解除归属。恰好一半时保持原归属。多个可接纳组重叠时优先选择更深的组。拖动期间组框保持尺寸，松手后才沿超出的方向扩框，必要时逐级扩大外层组。扩框保留成员的画布位置，只改变本次拖动对象的归属。手动拉伸组框后，成员归属判断使用当前可见尺寸，保存并重新打开仍保持一致。缩小普通组框不解除任何成员的父子关系；松开缩放手柄后把越界成员移回组内，若移动后重叠则在组内重新排列，必要时增加组框高度以容纳全部成员。

当前画布的普通布局组共用一个「内容缩放」开关。任意普通组工具栏最右侧的「更多」菜单提供开关；切换时同步应用到画布上的普通组和有序图片组，后续新建的组继承状态。纯图片组立即依据当前组框整理并记录原展示尺寸；组框缩小时，按可用宽高选择列数，图片、图片间距和内边距按同一比例缩小，图片保持宽高比。松开缩放手柄后确定布局；达到最小可操作尺寸后补足组框尺寸。放大或关闭开关时按原展示尺寸恢复。混合类型组记住统一开关，但仍按原有布局方式呈现，不因切换而移动非图片节点。动画帧批次和拆帧序列组沿用流程自身的布局规则。原图资产像素不受画布展示尺寸影响。

普通组的「设为有序组」和有序组的「转为普通组」默认位于「更多」菜单。组、图片、文本、视频、音频和功能卡片共用节点快捷工具栏与配置弹窗。外侧快捷栏的每项操作可独立开关文字，更多菜单及配置弹窗始终显示完整名称。操作可在两栏间拖动并调整顺序。按钮保留悬停名称与可访问名称。窄画布按可用宽度临时将靠后操作移入更多，偏好保持原设置。

偏好按节点类型保存在本机浏览器，支持同页即时同步与浏览器多页同步；保存、取消和恢复默认以当前类型为范围。旧组的节点内配置作为首次迁移来源，新偏好优先；当前画布存在多份旧配置时采用首先渲染的已配置组，后续同类组统一使用本机偏好。拆帧批次和序列帧组分别配置，以保留其操作权限。偏好不参与画布撤销。内容缩放的开关状态仍作用于整张画布。

点击组框边线或标题栏选中布局组；拖动标题栏移动整个组及其子节点。组的悬浮工具栏提供重命名、适应内容、折叠/展开、解除分组、删除和更多操作。解除分组只移除容器；删除组及内部画布实例必须支持撤销，且不删除被引用资产。

### 带数据语义的结果组

序列帧组和批量结果组既承担布局，也代表有类型的数据，因此可以显示端口。序列帧组输出一个有序图片集合；批量结果组接收处理模块输出，并可以向支持批处理的下游模块输出多个序列帧集合。端口固定在组标题栏左右两侧，展开和收起时不移动，避免连接线跳动。

布局组的成员输出与序列帧组的有序集合输出具有不同的类型。

### 批量结果组与序列帧组

动图拆帧的外层批量结果组使用比普通布局组更大的虚线框，顶部显示组数、总帧数和保存状态。内部序列帧组折叠时以第一帧封面、多层错位重影、来源名称、当前帧数和保存状态呈现。

第一版一次只允许展开一个序列帧组。多个折叠小组排列在顶部，共用下方序列编辑区；选择另一个小组时复用同一编辑区，不先收起外层组，也不改变其整体高度。画布内展开区属于快速编辑，显示真实帧节点并支持选择、多选、调整顺序、从序列移除、撤销和保存最终序列，同时提供“详细编辑”按钮。

点击“详细编辑”打开逐帧查看窗口。窗口打开后默认播放动画，不提供“动画播放/当前帧”模式切换；预览区下方的播放/暂停按钮是唯一播放状态控制。暂停后预览自然停留在当前帧；点击某一帧缩略图或上一帧、下一帧时，定位到目标帧并暂停，继续点击播放按钮后从该帧继续。详细窗口保留上一组、下一组、帧序号、时间位置和停留时间，不重复画布内的批量删帧与排序工具。

首次展开时，编辑区在约 180ms 内由上向下揭开并淡入；如果超出视口，只平移画布使其可见，不自动改变缩放。切换小组时，旧内容约 80ms 淡出，新内容轻微上移 8px 并在约 120ms 内淡入；收起时编辑区在约 180ms 内缩回。系统启用减少动态效果时取消位移并缩短或关闭动画。

拖动已展开的序列帧组时，拖动预览临时折叠为堆叠封面；释放后在新位置恢复原展开状态。从序列帧组拖出单帧默认执行“复制到画布”，不改变原序列；需要修改序列时使用明确的“从序列移除”。

## 批量裁切模块

以下描述是完整产品目标。首个原型只制作卡片外壳、左右端口、按钮占位区和预览占位区，不执行裁切，也不提前确定具体按钮。

图片节点工具栏的「裁切」已实现为独立流程，详见 [图片裁切 V01](design/prototypes/image-crop-v01-candidate.md)。网格设置支持行列、多网格、拖动分割线、模板和输出尺寸；下游裁切结果先以草稿预览，单张可调整并应用到其他结果，最后生成正式图片资产及可选有序组。已有有序组也可从播放预览进入裁切编辑。此入口与本节仍为占位的批量裁切模块分开。

- 用途：把一张包含多格内容的图集拆分为多张独立图片，例如把 16 格表情图拆成 16 张表情图片。
- 输入：可以接收一张或多张来源图片；多个图片模块可以连接到同一裁切模块进行批量处理。
- 布局：用户在卡片内部选择 16 张、20 张等裁切类型；精确的预设行列组合仍待确认。
- 结果顺序：裁切后的图片支持按横向顺序或纵向顺序排列。这里的方向描述结果排列与浏览顺序，不表示裁切网格本身的行列形状。
- 校正：裁切后可以选中某一结果，在固定裁切框内对内容进行缩放和移动。
- 应用范围：用户可以选择只把校正应用到当前结果，或应用到本次裁切的全部结果。
- 输出：裁切结果以图片集合进行批量输出，并保留集合内单张图片可被独立处理的能力。

## 功能模块扩展边界

画布核心不能把每一种功能卡片写死。每个功能模块需要能够独立声明自己的名称、类别、输入端口、输出端口、可配置项和卡片主体；新增模块时不应重写画布的连接规则。首版只建设项目内的模块注册边界，不建设第三方插件市场或动态安装系统。

处理结果如果需要持久保存、再次查看、拖入画布或继续连接，必须进入独立结果模块。处理模块卡片保持紧凑，只保留运行入口、必要设置、状态和错误摘要；进度等临时信息留在处理模块，序列帧集合等可复用数据留在结果模块。

“动图拆帧”输出一个动画帧批次组，其中每个来源动图对应一个序列帧小组。折叠序列帧小组以第一帧封面和后方多层错位重影表达有序图片集合，不使用文件夹图标；打开其中一组进入共用序列编辑区或逐帧查看。小组保留在批次内，「复制到画布」先保存帧资产，再创建一个可独立放置的有序组。动画帧编辑节点允许连接多个批次，集中查看与编辑，但更改仍回写所属的拆帧任务。

## 暂不覆盖

真实 AI 生成功能、自由画笔、复杂矢量路径、时间轴剪辑、多人光标和实时冲突合并不属于首批画布能力。“生成”节点当前只是预留卡片，不代表已接入 AI。
### 组内整理与动画帧避让

普通组的「整理」仅处理当前层，按静态图、动图、视频、其他节点、折叠组、展开组依次排列。素材使用统一展示格，展开组各自独占一行。整理可一次撤销。

动画帧批次一次展开一个序列组。折叠封面临时排列在上方，展开组独占下方一行，外框和编辑入口跟随调整。收起后恢复原来的封面坐标，帧顺序不变。

## 本地视频节点

底部视频入口创建空视频节点，点击卡片只选中，上传通过上方快捷工具触发；导入后画面可选中与拖动，不因点击而播放或暂停，播放与进度由底部独立控件操作。编辑按钮仅在有视频时显示，本轮标注待开放。外部视频可拖入画布，视频可以放在普通组中，有序图片组拒绝视频。导入门槛、格式与边界统一见[本地视频导入 V01](requirements/features/local-video-import.md)。

下载视频须先明确确认入库，再从素材库拖入画布。节点使用稳定资产预览 URL，默认暂停；不兼容原片通过独立兼容缓存播放，原片仍保留。已入库大视频按 5 分钟/500 MiB 提示选择进入编辑（待开放）或仍放画布，不重复复制原片；本地上传的现有限制不由此改动。下载与预览规则见[视频下载接口](api/video-downloads.md)。
