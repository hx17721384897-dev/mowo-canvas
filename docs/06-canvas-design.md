# 画布设计

## 交互模型

画布由节点、连线和视口组成。所谓无限画布是通过视口的 `x`、`y`、`zoom` 变换实现，不创建无限尺寸的 DOM。

第一版项目页采用“画布主体 + 右侧对话面板”的布局。底部放置节点入口；顶部工具栏暂不设置按钮。

## 节点入口

- 插入：一级入口，展开后显示文本、图片和视频三个二级选项。
- 裁切：一级入口，点击后创建裁切卡片；具体裁切功能后续定义。
- 生成：一级入口，当前创建节点形态但不接入模型或产生生成结果。
- 更多：为以后增加的节点类型预留入口。

## 基础操作

- 鼠标或触控板平移、缩放。
- 单选、框选和多选节点。
- 拖动节点。
- 从 Handle 创建连线。
- 删除、复制节点和连线。
- 撤销、重做。
- 适应视图与回到默认视图。
- 从底部常用节点栏或“更多节点”入口创建节点。
- 在画布空白处右键，通过菜单在点击位置附近创建节点。

## 行为规则

- 节点位置、尺寸和业务数据必须可序列化。
- 节点组件不直接读取本地文件系统或数据库。
- 素材节点只保存 `assetId`，由数据层解析素材。
- 文本输入时，画布快捷键不得干扰正常输入。
- 删除等破坏性操作必须支持撤销，或在不可撤销时二次确认。
- 自定义节点使用稳定组件引用并关注重渲染性能。

## 暂不覆盖

真实 AI 生成功能、自由画笔、复杂矢量路径、时间轴剪辑、多人光标和实时冲突合并不属于首批画布能力。“生成”节点当前只是预留卡片，不代表已接入 AI。
