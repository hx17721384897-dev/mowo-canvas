# 画布设计

## 交互模型

画布由节点、连线和视口组成。所谓无限画布是通过视口的 `x`、`y`、`zoom` 变换实现，不创建无限尺寸的 DOM。

第一版项目页采用“画布主体 + 右侧对话面板”的布局。底部放置节点入口；顶部工具栏暂不设置按钮。

整个项目页称为工作台，画布是工作台的核心区域。用户界面使用“模块”和“连接”；实现层使用 React Flow 的节点和连线模型。

## 节点入口

- 插入：一级入口，展开后显示文本、图片和视频三个二级选项。
- 裁切：一级入口，点击后直接创建批量裁切卡片；用户在卡片内选择网格数量与排列方式。
- 生成：一级入口，当前创建节点形态但不接入模型或产生生成结果。
- 更多：为以后增加的节点类型预留入口。
- 双击：在画布空白处提供快捷创建入口。

## 基础操作

- 鼠标或触控板平移、缩放。
- 单选、框选和多选节点。
- 拖动节点。
- 从 Handle 创建连线。
- 删除、复制节点和连线。
- 撤销、重做。
- 适应视图与回到默认视图。
- 从底部常用节点栏或“更多节点”入口创建节点。
- 在画布空白处右键，通过菜单在点击位置附近创建节点。
- 双击画布空白处，通过快捷创建入口添加模块。

## 行为规则

- 节点位置、尺寸和业务数据必须可序列化。
- 节点组件不直接读取本地文件系统或数据库。
- 素材节点只保存 `assetId`，由数据层解析素材。
- 文本输入时，画布快捷键不得干扰正常输入。
- 删除等破坏性操作必须支持撤销，或在不可撤销时二次确认。
- 自定义节点使用稳定组件引用并关注重渲染性能。
- 模块默认可以独立使用；只有存在明确输入或输出的模块才显示端口。
- 输入端口统一位于卡片左侧，输出端口统一位于卡片右侧，不使用底部端口。
- 一个模块可以有多个具名输入或输出端口，以表达不同内容类型；例如未来的拼接模块可以分别提供图片输入与文字输入。
- 端口需要声明可接收的内容类型以及单条或多条连接规则；连接时只允许兼容内容进入。
- 支持多连接的输入端口可以汇集多个上游来源，输出端口也可以连接多个下游模块。

## 批量裁切模块

- 用途：把一张包含多格内容的图集拆分为多张独立图片，例如把 16 格表情图拆成 16 张表情图片。
- 输入：可以接收一张或多张来源图片；多个图片模块可以连接到同一裁切模块进行批量处理。
- 布局：用户在卡片内部选择 16 张、20 张等裁切类型及横向、纵向排列方式；精确的行列与读取顺序仍待确认。
- 校正：裁切后可以选中某一结果，在固定裁切框内对内容进行缩放和移动。
- 应用范围：用户可以选择只把校正应用到当前结果，或应用到本次裁切的全部结果。
- 输出：裁切结果以图片集合进行批量输出，并保留集合内单张图片可被独立处理的能力。

## 功能模块扩展边界

画布核心不能把每一种功能卡片写死。每个功能模块需要能够独立声明自己的名称、类别、输入端口、输出端口、可配置项和卡片主体；新增模块时不应重写画布的连接规则。首版只建设项目内的模块注册边界，不建设第三方插件市场或动态安装系统。

## 暂不覆盖

真实 AI 生成功能、自由画笔、复杂矢量路径、时间轴剪辑、多人光标和实时冲突合并不属于首批画布能力。“生成”节点当前只是预留卡片，不代表已接入 AI。
