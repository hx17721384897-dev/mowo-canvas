# 模板选择

## 当前决定

采用轻量组合，不导入完整 SaaS Starter：

- Next.js 官方脚手架作为工程地基。
- React Flow 官方基础能力作为画布起点。
- shadcn/ui 只按需复制具体组件或页面外观。
- 数据、项目和素材能力由本项目按当前需求实现。
- 当前不导入登录或账户模板。

## 选择标准

候选模板必须满足：

1. 许可证允许计划中的使用方式。
2. 兼容项目实际采用的 Next.js 与 React 版本。
3. 不强制依赖海外托管、数据库、身份、邮件、支付或分析服务。
4. 可以在本地完整运行。
5. 依赖规模和代码复杂度与获得的能力相称。
6. 没有不透明遥测或未经说明的外部请求。
7. 安全维护状态明确。
8. 可以逐项理解、替换和删除。

## 引入流程

1. 明确要解决的具体问题。
2. 检查许可证、依赖、外部请求和环境变量。
3. 在独立 Git 分支或检查点中试用。
4. 只保留解决当前问题所需部分。
5. 运行类型检查、测试和构建。
6. 接受后更新本文件及相关架构文档。
7. 放弃时恢复试用前检查点，不在当前文档反复描述该候选。

登录页面模板只提供界面，不等于完成身份认证、密码存储、会话和权限控制。
