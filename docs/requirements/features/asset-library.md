# 资产库需求

## 目标

让画布中使用过的文字、图片和视频成为可长期管理、检索并再次拖回画布的资产，而不是随画布模块删除而丢失。

## 已确认需求

### REQ-ASSET-001 统一资产类型

文字、图片、动图和视频都属于资产。资产可以来自下载、本地导入、画布创建或功能模块输出；图片和视频一次可以产生一个或多个资产。

验收：资产库能够区分文字、图片和视频；单个内容和批量内容使用同一套资产身份与管理规则。

### REQ-ASSET-002 资产与模块实例分离

画布上的内容模块只是资产在当前画布上的一次放置。用户从画布删除模块时，只删除模块实例，不删除其引用的资产；用户可以从资产区再次把资产拖入画布。

验收：删除图片、视频或文字模块后，关联资产仍能在资产区找到；再次拖入后创建新的模块实例，不产生不必要的文件副本。

### REQ-ASSET-003 左侧功能与资产页签

工作流编辑器左侧顶部提供“功能”和“资产”两个一级页签。“功能”显示现有工具库；“资产”用于浏览和管理当前可用资产。提示词库页签当前不制作。

验收：两个页签职责清楚且可以切换；未出现不可用的提示词库占位页签。

### REQ-ASSET-004 批量与集合关系

同一来源产生的多张图片或多个视频可以组成有顺序的资产集合，例如一套表情包、一次多视频下载或裁切结果。集合中的每个资产仍可被单独使用。

验收：集合顺序能够保留；把其中一项拖入画布不要求同时拖入整个集合。

### REQ-ASSET-005 图片下载筛选界面

图片下载弹窗采用左侧大预览区、右侧缩略图与选择区。下载结果默认全选；取消勾选的缩略图降低颜色与视觉权重，但仍可识别并重新勾选。普通浏览状态下点击缩略图在左侧预览；动图默认播放并提供暂停能力。

验收：左右区域职责明确；取消勾选状态可见且可恢复；静态图片和动图都能在左侧预览。

## 待确认

- 资产页默认只显示当前项目资产，还是同时提供全局素材库范围。
- 资产页内部的搜索、类型筛选、集合分组、排序和预览方式。
- 全局素材库根目录的默认位置与迁移方式。
- 同一资产被多个模块实例引用时，内容编辑是同步更新、生成版本还是生成派生资产。
- 资产的主动删除、回收站、引用检查与恢复规则。
- 文字资产的自动保存时机与空白文字清理规则。
