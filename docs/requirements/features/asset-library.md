# 资产库需求

## 目标

让画布中使用过的文字、图片和视频成为可长期管理、检索并再次拖回画布的资产，而不是随画布模块删除而丢失。

## 已确认需求

### REQ-ASSET-001 统一资产类型

文字、图片、动图和视频都属于资产。资产可以来自下载、本地导入、画布创建或功能模块输出；图片和视频一次可以产生一个或多个资产。

验收：资产库能够区分文字、图片和视频；单个内容和批量内容使用同一套资产身份与管理规则。

### REQ-ASSET-002 资产与模块实例分离

画布上的内容模块只是资产在当前画布上的一次放置。用户从画布删除模块时，只删除模块实例，不删除其引用的资产；用户可以从资产区再次把资产拖入画布。

验收：删除图片、视频或文字模块后，关联资产仍能在资产区找到；再次拖入后创建新的模块实例，不产生不必要的文件副本。

### REQ-ASSET-003 左侧功能与资产页签

工作流编辑器左侧顶部提供“功能”和“资产”两个一级页签。“功能”显示现有工具库；“资产”用于浏览和管理当前可用资产。资产数量超过可视高度时，列表支持鼠标滚轮、触控板和触摸上下滚动。静止时不显示滚动条，滚动或拖动滑块时短暂显示细窄的悬浮滑块，停止操作后自动淡出；滑块不占用缩略图宽度，浏览器原生宽滚动槽始终隐藏。提示词库页签当前不制作。

验收：两个页签职责清楚且可以切换；大量资产可以滚动访问到底部；静止状态不显示滚动条，滚动时显示可拖动的细滑块且不挤压缩略图；未出现不可用的提示词库占位页签。

### REQ-ASSET-004 批量与集合关系

同一来源产生的多张图片或多个视频可以组成有顺序的资产集合，例如一套表情包、一次多视频下载或裁切结果。集合中的每个资产仍可被单独使用。

验收：集合顺序能够保留；把其中一项拖入画布不要求同时拖入整个集合。

### REQ-ASSET-005 图片下载筛选界面

图片下载弹窗采用左侧大预览区、右侧缩略图与选择区。下载结果默认全选；取消勾选的缩略图降低颜色与视觉权重，但仍可识别并重新勾选。普通浏览状态下点击缩略图在左侧预览；动图默认持续循环播放并提供暂停能力。预览媒体必须按原比例完整收纳在预览窗口内，不能覆盖控制区或弹窗其他区域；当前素材为 APNG 时，类型标识显示在“已下载图片”标题旁。点击弹窗外侧不关闭窗口；已有下载结果时，右上角关闭和底部关闭需要二次确认，确认关闭只隐藏窗口并保留任务与临时文件，重新打开后恢复结果，无需重新下载。正在下载时，底部操作明确显示“取消下载”，与普通关闭分离。

验收：左右区域职责明确；取消勾选状态可见且可恢复；静态图片和动图都能在左侧预览；播放状态下 APNG 不因源文件的有限循环次数而停帧；任意宽高比的媒体不越出预览窗口；类型标识不遮挡预览、控制或导入按钮；误点弹窗外侧不会关闭；关闭确认后再次打开仍能恢复已下载结果；只有明确执行“取消下载”才取消未完成任务。

### REQ-ASSET-006 当前项目资产

资产页默认展示当前项目已经关联的资产，不直接混入其他项目的全部内容。

验收：打开资产页时首先看到当前项目资产；其他项目资产需要通过明确的添加流程进入当前项目。

### REQ-ASSET-007 添加资产来源

资产搜索框旁提供“添加”入口。点击后可以选择“从本地添加”或“从历史画布添加”。从历史画布添加时，用户选择其他项目已有资产并引用到当前项目，不复制已经保存的物理文件。

验收：本地文件能够进入导入流程；历史画布资产能够被选择并出现在当前项目资产中；同一物理资产不会因跨项目引用而重复保存。

### REQ-ASSET-008 导入后的默认行为

下载或本地导入完成后，资产进入当前项目资产区，不自动在画布批量创建模块。用户从资产区选择需要的内容拖入画布。

验收：导入大量素材不会打乱当前画布；新资产在资产区可见并可拖入画布。

### REQ-ASSET-009 资产筛选与集合

资产页第一版提供全部、图片、视频和文字类型筛选；标题区域提供资产范围下拉选项，包括“当前项目资产”“画布上的资产”和“未在画布上的资产”。范围判断依据当前画布节点保存的 `assetId`，拖入或删除资产节点后同步更新。在“画布上的资产”范围内点击资产卡片时，画布自动平移和缩放到对应节点并选中；同一资产被放置多次时，应把所有对应节点纳入可视范围。资产集合保持来源顺序，第一版以逐项拖入为主。

验收：用户能够组合使用资产范围、类型和搜索条件；同一资产即使在画布放置多次也只计为一个资产；拖入或删除最后一个引用节点后范围结果正确更新；点击“画布上的资产”中的卡片可定位并选中相应节点，多处放置时可同时看到全部对应节点；集合成员可单独使用且不会一次创建大量节点。

### REQ-ASSET-010 手动保存文字资产

文字模块不会自动进入资产库。只有用户明确执行“保存为资产”后，文字内容才成为可复用的文字资产；空白文字不能保存。

验收：普通文字编辑不会制造大量无用资产；用户手动保存后可以从资产页再次拖入。

### REQ-ASSET-011 编辑与派生资产

模块位置、显示尺寸和连接属于模块实例状态，不修改原资产。真正改变内容的裁切、格式转换或媒体编辑生成派生资产；同一文字资产被复用后编辑时需要分离副本，避免意外覆盖其他位置。

验收：调整一个模块的展示不会改变其他模块；内容编辑可以追溯原始资产。

### REQ-ASSET-012 数据目录与回收站

首次运行时允许用户选择数据根目录，默认建议使用 Windows Documents 下的 `MOWO Canvas Data`；检测到云盘重定向时提示选择本地路径。机器缓存与日志使用 LocalAppData。资产回收站默认保留 30 天；仍被项目或画布引用的资产禁止进入回收站。

验收：用户数据与源码分离；路径清晰可打开；画布删除不进入资产回收站；误删资产可在保留期内恢复。

### REQ-ASSET-013 第一版图片范围

第一版图片基础支持 PNG、APNG、JPEG、WebP 和 GIF；SVG 暂不支持。LINE 动态贴纸按 `image/png` 验证并保留动画数据。单张图片、单批数量和总量都必须在服务端验证并提供明确超限提示。

验收：支持格式能够被验证、预览和导入；不支持或超限文件不会写入正式素材库。

### REQ-ASSET-014 下载适配器边界

图片下载界面与资产导入流程不绑定具体平台解析器。LINE 使用 TypeScript 适配器重新实现，复用用户旧工具中已经验证的商品识别、元数据、CDN、Emoji ZIP 和 APNG 处理规律；不把旧 Flask 页面、任务字典和下载目录引入 MOWO。B 站视频下载精简首版已确认，见[下载 PRD](video-download.md)；引擎已验证，正式下载弹窗与任务入库仍待集成。

验收：增加或替换平台适配器不需要重写资产页、预览选择或导入逻辑；LINE 专有字段不会进入客户端弹窗状态。

### REQ-ASSET-015 LINE 下载任务

用户提交受支持的 LINE 商店链接后，系统创建可查询的本地下载任务。任务记录解析、下载、可导入、完成、失败或取消状态；下载文件先进入任务临时目录，页面刷新后仍可恢复已完成结果。

验收：页面能够显示任务编号、进度和分类错误；失败不会泄露本机路径或底层堆栈；没有成功文件的任务不能进入导入状态。

### REQ-ASSET-016 LINE 安全限制

只接受 HTTPS 的 LINE 商店与短链接格式；所有实际网络请求只访问受信任的 LINE CDN。单文件、ZIP、文件数量和解压后总体积必须限制；下载结果必须验证 PNG 文件头。代理由服务端可选配置提供，不写入前端或数据库。

验收：伪造域名、超限文件、非法 ZIP 和非 PNG 内容会被拒绝；日志和响应不包含代理凭据。

### REQ-ASSET-017 下载结果选择与导入

下载完成后默认全选，用户可逐项取消、恢复、预览和切换。导入时选中项通过资产模块进行内容去重并形成有顺序的资产集合；未选项由用户选择立即删除或移动到独立下载归档，不自动成为当前项目资产。

验收：取消项视觉变淡；选中项导入后出现在当前项目资产区；重复内容不产生第二个物理文件；集合顺序与下载顺序一致。

### REQ-ASSET-018 从文件夹拖入图片

用户可从 Windows 文件夹选中一张或多张图片，直接拖到画布位置导入。支持 PNG、JPEG、WebP、GIF 和按 PNG 导入的 APNG，单次最多 500 张，每张不超过 50MB。格式不支持或超限时显示原因。拖入文件夹本身时提示打开文件夹选择图片。

文件通过现有项目资产接口入库并复用内容去重。连续编号的静态图片按编号组成有序组，其他图片 8 张及以上自动打组，少量图片按网格放置。拖入普通组后归入该组；拖入有序组前检查静态内容，通过后追加到末尾，保留原有帧。导入失败不创建空白画布节点；已入库但未通过有序组检查的图片可从资产栏再次使用。

### REQ-ASSET-019 按来源整理视图

资产范围标题旁提供视图设置，默认保持平铺；选择「按来源」后，按下载、导入等已接入来源折叠展示。文件夹、下载批次和素材以固定尺寸方块排列，侧栏变宽时增加列数。点击文件夹或批次逐层进入，面包屑可返回；原始素材卡片保留放入或定位画布的操作，以独立的「查看产物」入口进入相关产物层。一次下载入库的多个原始素材按批次收纳；单独导入的素材独立排列。用户可新建手动文件夹，跨批次整理原始素材。衍生资产只从相关原始素材的产物区进入；多个源共同生成的结果在各源下显示指向同一资产的关联入口，不复制结果。手动文件夹不接收衍生资产，也不改变原始来源。详细边界与待定交互见[按来源整理 V01](../../design/asset-source-view-v01.md)。

验收：切回平铺后仍能按原方式浏览；整理原始素材不改变画布节点或资产文件；拆帧、裁切和拼接结果可从对应源头找到；多源结果在不同入口打开时身份一致。

### REQ-ASSET-020 素材信息中的位置与来源

画布素材的信息按钮与资产栏卡片可查看同一素材信息。分别展示当前项目内的整理位置和历次入库来源；来源素材和相关产物逐项显示名称及类型。在当前画布有实例的条目提供醒目的「定位画布」操作，未放置的条目保留可搜索名称和中性状态；资产搜索可以找到折叠产物并展示来源路径。从下载批次移入手动文件夹后，批次列表不留重复卡片或占位，原批次仍可在信息中查看。相同内容再次导入当前项目时仅保留一个整理位置，并提示定位，不自动移动已有素材。

验收：移动原始素材后信息中的当前位置更新、下载批次历史不丢；重复导入不产生第二张资产卡片；从画布节点和资产栏打开信息时，项目内的位置与来源一致；来源和产物条目能按真实画布状态定位或通过名称搜索到。

## 本地视频

视频原片通过画布拖入或空视频节点上传，导入范围与超限分流以[本地视频导入 V01](local-video-import.md)为准。视频同样复用资产身份和项目关联，删除画布实例不删除原片。
