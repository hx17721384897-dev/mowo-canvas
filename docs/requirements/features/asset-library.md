# 资产库需求

## 目标

让画布中使用过的文字、图片和视频成为可长期管理、检索并再次拖回画布的资产，而不是随画布模块删除而丢失。

## 已确认需求

### REQ-ASSET-001 统一资产类型

文字、图片、动图和视频都属于资产。资产可以来自下载、本地导入、画布创建或功能模块输出；图片和视频一次可以产生一个或多个资产。

验收：资产库能够区分文字、图片和视频；单个内容和批量内容使用同一套资产身份与管理规则。

### REQ-ASSET-002 资产与模块实例分离

画布上的内容模块只是资产在当前画布上的一次放置。用户从画布删除模块时，只删除模块实例，不删除其引用的资产；用户可以从资产区再次把资产拖入画布。

验收：删除图片、视频或文字模块后，关联资产仍能在资产区找到；再次拖入后创建新的模块实例，不产生不必要的文件副本。

### REQ-ASSET-003 左侧功能与资产页签

工作流编辑器左侧顶部提供“功能”和“资产”两个一级页签。“功能”显示现有工具库；“资产”用于浏览和管理当前可用资产。提示词库页签当前不制作。

验收：两个页签职责清楚且可以切换；未出现不可用的提示词库占位页签。

### REQ-ASSET-004 批量与集合关系

同一来源产生的多张图片或多个视频可以组成有顺序的资产集合，例如一套表情包、一次多视频下载或裁切结果。集合中的每个资产仍可被单独使用。

验收：集合顺序能够保留；把其中一项拖入画布不要求同时拖入整个集合。

### REQ-ASSET-005 图片下载筛选界面

图片下载弹窗采用左侧大预览区、右侧缩略图与选择区。下载结果默认全选；取消勾选的缩略图降低颜色与视觉权重，但仍可识别并重新勾选。普通浏览状态下点击缩略图在左侧预览；动图默认播放并提供暂停能力。

验收：左右区域职责明确；取消勾选状态可见且可恢复；静态图片和动图都能在左侧预览。

### REQ-ASSET-006 当前项目资产

资产页默认展示当前项目已经关联的资产，不直接混入其他项目的全部内容。

验收：打开资产页时首先看到当前项目资产；其他项目资产需要通过明确的添加流程进入当前项目。

### REQ-ASSET-007 添加资产来源

资产搜索框旁提供“添加”入口。点击后可以选择“从本地添加”或“从历史画布添加”。从历史画布添加时，用户选择其他项目已有资产并引用到当前项目，不复制已经保存的物理文件。

验收：本地文件能够进入导入流程；历史画布资产能够被选择并出现在当前项目资产中；同一物理资产不会因跨项目引用而重复保存。

### REQ-ASSET-008 导入后的默认行为

下载或本地导入完成后，资产进入当前项目资产区，不自动在画布批量创建模块。用户从资产区选择需要的内容拖入画布。

验收：导入大量素材不会打乱当前画布；新资产在资产区可见并可拖入画布。

### REQ-ASSET-009 资产筛选与集合

资产页第一版提供全部、图片、视频和文字类型筛选，并能区分已在画布与未在画布的资产；资产集合保持来源顺序，第一版以逐项拖入为主。

验收：用户能够按类型和是否已放置查找资产；集合成员可单独使用且不会一次创建大量节点。

### REQ-ASSET-010 手动保存文字资产

文字模块不会自动进入资产库。只有用户明确执行“保存为资产”后，文字内容才成为可复用的文字资产；空白文字不能保存。

验收：普通文字编辑不会制造大量无用资产；用户手动保存后可以从资产页再次拖入。

### REQ-ASSET-011 编辑与派生资产

模块位置、显示尺寸和连接属于模块实例状态，不修改原资产。真正改变内容的裁切、格式转换或媒体编辑生成派生资产；同一文字资产被复用后编辑时需要分离副本，避免意外覆盖其他位置。

验收：调整一个模块的展示不会改变其他模块；内容编辑可以追溯原始资产。

### REQ-ASSET-012 数据目录与回收站

首次运行时允许用户选择数据根目录，默认建议使用 Windows Documents 下的 `MOWO Canvas Data`；检测到云盘重定向时提示选择本地路径。机器缓存与日志使用 LocalAppData。资产回收站默认保留 30 天；仍被项目或画布引用的资产禁止进入回收站。

验收：用户数据与源码分离；路径清晰可打开；画布删除不进入资产回收站；误删资产可在保留期内恢复。

### REQ-ASSET-013 第一版图片范围

第一版图片基础支持 PNG、APNG、JPEG、WebP 和 GIF；SVG 暂不支持。LINE 动态贴纸按 `image/png` 验证并保留动画数据。单张图片、单批数量和总量都必须在服务端验证并提供明确超限提示。

验收：支持格式能够被验证、预览和导入；不支持或超限文件不会写入正式素材库。

### REQ-ASSET-014 下载适配器边界

图片下载界面与资产导入流程不绑定具体平台解析器。LINE 使用 TypeScript 适配器重新实现，复用用户旧工具中已经验证的商品识别、元数据、CDN、Emoji ZIP 和 APNG 处理规律；不把旧 Flask 页面、任务字典和下载目录引入 MOWO。B 站下载继续延后。

验收：增加或替换平台适配器不需要重写资产页、预览选择或导入逻辑；LINE 专有字段不会进入客户端弹窗状态。

### REQ-ASSET-015 LINE 下载任务

用户提交受支持的 LINE 商店链接后，系统创建可查询的本地下载任务。任务记录解析、下载、可导入、完成、失败或取消状态；下载文件先进入任务临时目录，页面刷新后仍可恢复已完成结果。

验收：页面能够显示任务编号、进度和分类错误；失败不会泄露本机路径或底层堆栈；没有成功文件的任务不能进入导入状态。

### REQ-ASSET-016 LINE 安全限制

只接受 HTTPS 的 LINE 商店与短链接格式；所有实际网络请求只访问受信任的 LINE CDN。单文件、ZIP、文件数量和解压后总体积必须限制；下载结果必须验证 PNG 文件头。代理由服务端可选配置提供，不写入前端或数据库。

验收：伪造域名、超限文件、非法 ZIP 和非 PNG 内容会被拒绝；日志和响应不包含代理凭据。

### REQ-ASSET-017 下载结果选择与导入

下载完成后默认全选，用户可逐项取消、恢复、预览和切换。导入时选中项通过资产模块进行内容去重并形成有顺序的资产集合；未选项由用户选择立即删除或移动到独立下载归档，不自动成为当前项目资产。

验收：取消项视觉变淡；选中项导入后出现在当前项目资产区；重复内容不产生第二个物理文件；集合顺序与下载顺序一致。
