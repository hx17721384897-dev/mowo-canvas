# 首页与导航需求

## 目标

让用户在首页直接管理和打开历史画布，并清楚地区分“画布项目中心”与“当前工作流编辑器”。

## 已确认需求

### REQ-HOME-001 首页导航

首页保留独立的导航区域。第一版可访问首页、项目和技能，并提供进入设置的入口。首页导航与进入画布后的工作流工具栏不是同一套侧栏。

验收：首页导航不会在进入编辑器后原样占用工作流工具区；用户可以找到设置入口。

### REQ-HOME-002 历史画布主体

首页主体用于展示用户已经创建的历史画布，不设置 ChatGPT 式的大型语言输入框。每个历史画布以可辨认的项目卡片呈现。

验收：首页主要内容是画布项目集合；点击卡片进入对应画布，不出现以聊天作为新建任务主入口的布局。

### REQ-HOME-003 新建画布

历史画布区域提供清晰的“新建画布”按钮或卡片。点击后创建一个空白项目并进入其工作流编辑器。

验收：新建操作只创建一个项目；进入的是该项目的空白画布。

### REQ-HOME-004 历史画布恢复

点击历史画布后，恢复该项目保存的节点、连线、视口和关联对话。

验收：打开历史画布不会创建新项目，也不会加载其他项目的数据。

## 待确认

- 首页左侧导航的最终栏目、宽度与折叠方式。
- 历史画布卡片需要展示的缩略图、更新时间、状态和快捷操作。
- 历史画布的排序、搜索、筛选和固定能力。
- 新建画布时直接使用默认名称，还是先输入名称。
