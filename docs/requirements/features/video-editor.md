# 视频观察与片段回画布 PRD

> 状态：观察、精确帧读取、片段保存、分镜及人工校正已接入。用户反馈分镜正常，剪辑的真实素材验收见[剪辑设计](../../design/video-cutting-design.md#真实素材验收)。长片、复杂时间戳和跨电脑分镜仍待专项确认。入口来自[本地视频导入](local-video-import.md)和 B 站视频资产。技术边界见[视频编辑页技术设计](../../design/video-editor-architecture.md)，专项证据见[实施记录](../../design/video-editor-progress.md)。

## 目标与范围

用户进入专门页面后，先看视频，再按源视频实际帧观察画面，选择时间片段导回当前画布。原片保持不变。首期是观察与选片段，不提供多轨剪辑、转场、音频编辑或空间裁画面。自动镜头检测和人工校正切点安排在第二期；页面布局为这部分预留位置。

## 页面与操作

播放、暂停或定位时，左侧当前镜头高亮与帧时间轴、底部总览的蓝色区间使用同一源帧所属镜头范围；首镜头从帧 0 开始，切点帧归入右侧镜头，最后镜头延伸到总帧数。手动待保存的片段选区用虚线独立呈现，播放跨镜头不会修改右侧片段起止帧；没有有效分镜结果时，蓝色区间继续表示手动选区。

播放中的时间轴播放头按浏览器实际呈现的视频帧同步，使用源 PTS 映射帧号，不仅依赖低频播放时间事件。暂停或定位后停止播放跟踪，保留准确选帧；不支持视频帧回调时使用动画帧更新作为回退。

播放控制条悬浮在画面下沿，鼠标移入或移动时显示，停止操作约 2 秒后隐藏，移出约 0.7 秒后隐藏；键盘聚焦控制时保持可见。控制条层级高于准确帧图，图片、放大和平移不会盖住控制条。播放入口集中在进度控制条，下方工具栏不再重复放置播放、上一帧、下一帧按钮。

Ctrl＋滚轮在画面区执行观察缩放（25%–400%），在时间轴执行时间范围缩放；拦截默认浏览器缩放。蓝色总览滑轨位于底部时间轴工作区最下沿。观察缩放不改变片段输出。

后续画面裁切阶段再讨论固定输出画布、视频相对画布移动及黑边是否进入实际输出。目前只有观察缩放和平移，尚未实现改变输出画面。

观察页工作区支持调整尺寸：拖动左侧片段列表与播放器之间、右侧片段选择与播放器之间的竖向分隔线调整面板宽度；拖动时间轴上沿的横向分隔线调整底部高度。悬停/聚焦时分隔线高亮，显示相应调整光标；可用方向键微调，双击恢复默认尺寸。设置最小面板宽度与中心保留空间，防止拖动后控件消失；播放器自适应剩余空间，侧栏内容独立滚动。三个工作区的尺寸按当前画布分别保存在本机浏览器；同一画布切换视频、刷新或重新进入时自动恢复。窗口较小时仅收束当前显示尺寸，不覆盖用户保存的偏好，窗口恢复后沿用原尺寸。双击恢复默认会同步更新该画布的尺寸偏好。

| 区域 | 首期行为 | 第二期增加 |
| --- | --- | --- |
| 顶部 | 返回所属画布、视频名称、索引状态、片段保存状态 | 当前分镜任务状态 |
| 中央 | 大画面、播放/暂停、音量、倍速、适应窗口、放大平移、源帧号与时间码 | 从镜头列表跳转观察 |
| 下方 | 可缩放的时间轴、总览条、播放头、帧选择、起止点和选中区间 | 镜头边界与检测进度叠加 |
| 左侧 | 已手动保存的片段列表；选中后定位与突出显示 | 「开始分镜」按钮、镜头缩略图列表及检测进度 |
| 右侧 | 当前片段的起止帧、时长、预览区间、保存片段、导回画布 | 当前镜头切点修正、拆分与合并 |

进入页面立即显示播放器；原片或兼容预览可用时，用户点击播放无需等待帧索引或镜头检测。原片不兼容且兼容预览仍在生成时，明确显示预览准备状态和进度，不声称已经可以播放。浏览器不允许自动有声播放时，显示可直接操作的播放按钮。页面状态必须区分「预览准备中」「可以播放」「帧索引进行中」「准确逐帧可用」「检测进行中」；后台索引失败不能让已可播放的视频变成不可看。

### 时间轴交互细则（候选）

拖动时间轴时先显示浏览器预览，不等待准确源帧图片；松手后异步校准，校准中明确标示预览状态。已查看过的源帧在缓存容量范围内直接复用。新操作使旧响应失效，防止快速拖动后旧画面覆盖新位置；正式片段保存继续使用准确索引边界。

观察页加载反馈：点击画布卡片、素材库片段入口或本地视频入库后的编辑入口时，立即显示「正在打开视频观察页」进度提示；页面准备完成后自动移除。视频首帧尚未就绪时，在播放器区域显示「正在读取视频」；生成兼容预览时显示对应阶段。无法测量实际百分比的加载使用流动进度条，不模拟百分比；共享组件允许其他有真实进度的操作传入百分比。加载不应遮住已经可以使用的逐帧画面。

| 操作 | 预期反馈 |
| --- | --- |
| 单击刻度区 | 播放头定位到相应源帧；未建好索引时仅做时间定位，并明确显示“帧号待确认”。 |
| 拖动播放头 | 中央画面跟随预览；高频拖动可以跳过中间请求，但松手后必须显示最终目标帧。 |
| 滚轮配合缩放键或使用缩放按钮 | 以指针位置为锚点改变可见帧数；当前区间、播放头和切点不随缩放改变。具体快捷键在界面原型阶段确定。 |
| 拖动总览条的可见窗口 | 平移详细时间轴，不改变播放位置；“适应全片”恢复全局视图。 |
| 聚焦时间轴后按左右方向键 | 自动暂停并显示准确源帧；连续按键按帧序前进/后退，帧号与时间码同步。 |
| 设为起点/终点或拖动区间手柄 | 吸附到有效帧边界，右侧同步显示起止帧、起止时间码和片段时长；预览选区无需先保存。 |
| 开启选区循环 | 从选区起点播放，到终点后回到起点；关闭后恢复普通全片播放。空选区或只有一个边界时不可开启。 |
| 放大并拖动画面 | 放大观察细节时保留当前帧与播放位置；“适应窗口”恢复整体画面，画面放大不改变导出或拆帧内容。 |

时间轴需在全片级、镜头级和单帧级缩放下保持可读；在单帧级显示帧格，在全片级聚合刻度与标记，不要求为长视频绘制每一帧缩略图。

## 首期需求与验收

| ID | 需求 | 可观察的验收标准 |
| --- | --- | --- |
| VE-01 | 从所属项目的视频资产打开编辑页，并能返回同一画布。 | 已入库视频可直接打开；大本地文件选择“进入编辑”后须先完成安全接收与资产登记，再打开编辑页；接收失败时不产生虚假资产。返回后原画布仍可用。大文件入口按下方已确认流程处理。 |

| VE-03 | 时间轴提供全片总览、可见区间、缩放、平移和播放头。 | 适应全片、以鼠标位置为中心缩放、拖动可见区间均能定位；播放头离开可见区时可跟随，用户手动查看别处时不强制拉回。 |

| VE-05 | 通过时间轴帧选择及左右方向键提供逐帧与指定帧定位。 | 暂停状态下每次操作恰好移动一个源显示帧；首末帧不会越界；尚未就绪时明确提示并在就绪后可继续，不能显示错误帧却声称成功。 |
| VE-06 | 连续播放与逐帧观察切换。 | 播放时可暂停在当前画面，逐帧后可从选定帧附近恢复播放；若浏览器解码导致切换延迟，显示定位中，不静默跳到另一帧。 |
| VE-07 | 手动设置时间片段的起点和终点，并预览所选区间。 | 两端吸附源帧；不可保存零帧或反向区间；区间长度、时间码和右侧数值同步；允许保存多个片段且互不改变原片。 |

| VE-08a | 从片段视频卡片导出独立视频。 | 片段卡片的「导出视频片段」按已保存的起止帧生成 MP4，导出帧数与片段范围一致，原片不改变；失败时不留下正式资产或草稿。 |
| VE-09 | 处理不支持播放、索引失败或源文件缺失。 | 浏览器无法播放原片时尝试兼容预览并展示进度；预览失败时保留原片与重试入口，画面明确显示不可播放。索引长时间未完成时仍可播放和查看进度，允许取消或重试分析；准确逐帧和按帧保存片段不可用时说明原因。源文件缺失时禁用保存/导回，避免产生无效片段。 |
| VE-10 | 离开并重新进入后保留已保存片段与用户主动保存的草稿。 | 页面内离开时提供保存草稿、放弃选区、继续编辑；重新进入可恢复草稿；未保存的选区不能误称已经保存。 |
| VE-15 | 首期提供选区循环播放。 | 起止边界有效时可开关循环；循环只改变预览播放，不修改原片或已保存片段。 |
| VE-16 | 首期提供画面放大、平移和适应窗口。 | 暂停和播放时均可观察局部；放大倍率与位置不改变帧号、选区或片段实际内容。 |

帧与区间的产品语义：帧号从 0 开始；片段包含起点帧、不包含终点边界帧，即 `[startFrame, endFrame)`。界面显示可用的最后一帧，内部终点可等于总帧数。时间码显示以源视频显示帧时间戳为准；以整数帧保存选择，避免小数秒舍入使片段偏移。**正式保存片段必须等待准确源帧索引就绪**；此前可以播放和粗选时间范围，但只能保存草稿，不能创建正式片段资产。索引就绪后用户查看吸附到源帧的边界并确认保存；已保存片段的边界不因后续分析而自动变化。正式拆帧应读取原片，不从低清兼容预览取帧。

### 多片段命名与离开提示（已确认）

同一原片可保存多个片段。默认名称采用「原视频名 · 片段 01」「原视频名 · 片段 02」；去掉原文件扩展名，编号按该原片在当前项目中成功保存的片段递增，删除后不重排或复用旧号。保存前可直接改名，重名不影响片段身份；列表同时显示起止时间，便于分辨同名片段。原视频改名不自动改写已经保存的片段名称。

用户通过页面内返回画布、切换素材或导航离开时，若存在未保存的有效选区，显示「保存为草稿 / 放弃选区 / 继续编辑」。选择草稿后保存当前原片、起止帧和可选名称，下次打开本视频时提示恢复；草稿不进入正式片段列表和画布，也不占用正式片段编号。保存正式片段后该选区不再触发离开提示；若后来又修改边界，则再次视为未保存。关闭浏览器标签或刷新时只能使用浏览器的通用离开警告，无法在系统弹窗中提供上述三个自定义按钮；用户应先在页面内选择保存草稿。

### 片段回画布

片段继续使用现有普通视频卡片的外观、尺寸调整和节点工具栏，不新建另一种可见卡片。卡片需要新增片段身份和来源信息，在播放时限制为所选起止范围，并以片段自身时长显示进度；不得把完整原片误呈现为已截取片段。用户从卡片进入编辑页时回到对应原片和片段边界。片段暂以原片引用保存，不因放入画布就生成独立 MP4；独立文件导出另行设计。现有卡片仅以原片 URL 接入浏览器原生控制，片段范围控制属于本功能需补的行为。

保存片段与放入画布是两个数据动作。界面同时提供「仅保存到素材库」和「保存并放入画布」：前者只创建片段素材，后者先保存、成功后再创建画布卡片，不能出现画布卡片已创建而片段保存失败。保存后片段进入**当前项目的素材库**，可再次拖到同一画布；单纯保存不自动创建节点。片段以独立身份引用原片及边界，不复制视频字节。存在片段引用时不得直接永久删除原片；项目删除或素材回收须遵守现有资产引用保护。删除某个画布片段卡片不删除素材库片段。

从已保存片段的素材卡或画布卡片选择「编辑」时，打开原片并带入该片段的边界作为新选区。用户调整后执行任一保存操作，**另存为新的片段身份**，按当前原片的下一个编号命名；原片段、素材库中其他引用及已有画布卡片均保持原边界和名称。「保存并放入画布」新增一张引用新片段的卡片，不替换发起编辑的旧卡片。首期不提供就地覆盖已保存片段。

## 大视频进入编辑页：已确认的流程

现有 5 分钟/500 MiB 阈值只是**画布放置提示阈值**，不能同时充当视频入库上限；当前本地上传接口仍以该值拒绝文件，实现时需调整。用户选择「进入编辑」或「仍放到画布」后，均先流式写入受控临时区，展示接收/校验进度；校验成功后按内容复用或保存原片，关联当前项目资产，再分别打开编辑页或创建普通视频卡片。接收途中取消或失败只清理未提交的临时文件；一旦正式入库，用户离开编辑页但未保存片段，原片仍在素材库。帧图、索引、兼容预览属于可重建缓存，不代替正式原片。

下载来源已在用户确认后成为正式资产时，从素材库拖入画布：大视频提示「进入编辑」或「仍放到画布」；前者打开同一资产的编辑页，后者建立普通视频卡片，不再次保存文件。若下载任务还处于“待确认入库”，先走下载确认流程，不把任务临时文件当成编辑资产。本地大视频也提供相同的两个去向；选择直接放画布不触发自动镜头检测。

素材库与画布目前没有应用级**总容量配额**；可用容量实际受所选数据磁盘约束。新流程不沿用 500 MiB 作为硬上限，也不承诺无限大文件一定可接收。实际接收须核查可用空间，空间不足时在正式入库前拒绝并说明原因；单文件技术上限和临时空间预留在大文件技术验证后确定。一个原片在画布上多次放置或派生多个片段不重复复制原片。

## 片段拆帧的分期

本轮首期验收止于「片段保存为素材并放回画布，可播放所选范围」。片段卡片进入视频拆帧的入口、逐帧批量提取、输出有序图片组与来源关系属于后续独立阶段，不以现有动图拆帧代码自动视为已完成。设计片段身份时保留 `sourceAssetId` 与边界，供后续拆帧消费；首期界面不展示可点击但尚未实现的“片段拆帧”。

## 第二期优先需求

进入编辑页不会自动启动镜头检测。左侧先显示可直接操作的「开始分镜」按钮；用户点击后才为当前原片建立分析任务，并在原位置显示真实进度和已确认的镜头。点击前，视频可播放、逐帧查看、设置片段边界、保存片段与回画布；源帧索引仍按这些操作所需的现有机制准备，不等同于启动分镜。分析进行中，上述手动操作仍可使用。再次进入页面时，已有结果直接显示，正在运行的任务继续显示状态，不重复启动；分析失败时在左侧显示原因与「重试分镜」。

| ID | 需求 | 可观察的验收标准 |
| --- | --- | --- |
| VE-11 | 用户点击左侧「开始分镜」后才在后台检测镜头，并逐步呈现结果。 | 新打开且从未分镜的原片不会自动排队；点击一次只建立一个有效任务，左侧显示已确认镜头和剩余分析状态；播放与手动片段操作不等待检测，失败不删除手动片段且可重试。 |

## 视频片段剪辑（分阶段实施中）

用户从当前视频观察页进入剪辑：上方画面和源帧时间轴继续用于查看原片与分镜；在源帧时间轴下方增加视频编辑区。移除源帧时间轴下方「蓝色：当前镜头 · 虚线：待保存片段选区」说明文字，保留区间与切点本身的可视表达。原片初次进入编辑区时呈现为一个完整片段，用户可拆分、修剪、删除和调整片段顺序；原片及分镜结果不随这些操作改变。编辑区表达成片顺序，源帧时间轴始终表达原片帧序，不能因成片片段重排而重排分镜切点。

## 已确认与后续细化

已确认首期加入选区循环与画面放大平移；同一原片可保存多个片段，采用上文默认命名；页面内离开时可主动保存草稿；片段沿用现有视频卡片，播放条按片段时长显示，拖动和播放限制在片段范围；第二期由用户点击左侧按钮主动开始分镜。尚需在界面原型中细化快捷键、卡片控件样式与窄屏布局，这些不改变以上产品规则。播放边界的实际精度与异常素材的处理按技术设计验证。
