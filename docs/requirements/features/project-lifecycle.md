# 项目生命周期需求

## 目标

让用户从首页创建或打开画布项目，并在以后重新进入时恢复同一份工作流和对话上下文。

## 产品关系

第一版采用“一项目一画布”：项目是保存边界，画布是编辑区域，工作流是画布上的节点与连线，对话是项目的关联记录。

## 已确认需求

### REQ-PROJECT-001 创建空白画布

用户通过首页历史画布区域中的“新建画布”入口创建空白项目并进入工作流编辑器。首页不通过发送聊天消息创建项目。

验收：创建成功后得到稳定项目标识；一次操作只创建一个项目。

### REQ-PROJECT-002 进入工作流编辑器

创建或打开项目后进入专门服务当前工作流的编辑器页面。编辑器不沿用首页侧栏，而是显示工作流工具区、顶部工具栏、底部常用工具栏和右侧对话面板。

验收：首页导航与编辑器工具布局可以清楚区分；进入失败不会创建重复项目。

### REQ-PROJECT-003 恢复项目

从历史画布进入时，恢复对应项目的节点、连线、视口和对话记录。

验收：重新打开后恢复该项目保存的节点、连线和视口，不会进入空白新画布，也不会加载其他项目的数据。画布停止操作后自动防抖保存，顶部“保存”可立即保存，离开页面时会提交尚未保存的最新状态。

### REQ-PROJECT-004 本地优先

第一版项目只保存在本机，不依赖登录、云端服务或海外托管。

验收：断网状态下仍可创建、打开和编辑本地项目。

### REQ-PROJECT-005 基础项目管理

项目列表支持打开、重命名和删除本地项目。删除属于破坏性操作，必须提供明确确认或可恢复机制。

- 首页只保留「我的画布」主标题。卡片显示真实项目，使用 4:3 封面、节点和连线数量及更新时间。有图片时使用画布中的首张图片填充封面，无图时居中显示画布图标和名称。
- 支持按名称搜索。排序默认最新创建，可切换最近更新或最早创建。更新项目不会改变创建时间排序。新画布默认使用「无限画布 N」递增命名。
- 重命名在卡片标题原位编辑，Enter 或「保存」提交，Esc 取消。首页「选择」进入多选模式，点击卡片勾选或取消勾选，「取消选择」退出并清空选择。
- 单项或批量删除均在确认后执行，确认提示列出数量、名称及节点和连线会一并移除。删除画布保留素材原文件。批量删除以一次数据库事务执行。

验收：重命名后所有项目入口同步显示新名称；删除不会误伤其他项目。

## 待确认

- 新项目默认命名与手工命名规则。
- 首页是否需要搜索、复制、筛选、排序和固定项目。
