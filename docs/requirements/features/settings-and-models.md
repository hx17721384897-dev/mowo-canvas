# 设置与模型接入需求

## 目标

为本地画布提供语言模型和后续生图模型的设置入口，秘密配置只由本机服务端读取。

## 已确认需求

### REQ-SETTINGS-001 设置入口

产品需要提供设置入口，并在设置中预留模型 API 管理区域。设置入口的最终位置和页面结构后续确认。

验收：原型能表达设置入口；模型能力不会散落在多个不一致的页面中。

### REQ-SETTINGS-002 模型 API 管理

未来支持分别管理语言模型和生图模型的 API 配置，包括服务商、接口地址、模型和密钥等必要信息。首个原型只做结构，不连接真实服务，也不要求输入真实密钥。

验收：语言模型和生图模型配置可以区分；未配置时界面显示明确状态。

### REQ-SETTINGS-003 密钥安全

API 密钥不得写入前端代码、公开环境变量或 Git。界面展示时必须遮蔽密钥；正式存储方案在接入模型前单独评审。

验收：原型和示例数据不包含真实密钥；前端无法获得可直接读取的秘密配置。

## 已确认的后续方向

基础文字对话按已确认的 [Agent 实施计划](../../ai/agent-implementation-plan.md) 实施：按画布保存历史、流式回复、停止并保留部分内容、复制与失败后重新生成；断线先恢复原请求，不能自动重复付费提交。当前实现及验收边界见 [V1 进度](../../ai/v1-progress.md)。

- 右侧对话面板调用已配置的语言模型或生图模型。
- 生图结果直接成为当前画布上的图片模块。
- 模型接入发生在核心画布与本地保存稳定之后，不属于首个原型。

## 待确认

- 第一批支持哪些国内可访问或可自托管的模型服务。
- API 配置是全局生效，还是允许项目覆盖。
- 本地密钥采用操作系统凭据库、加密文件还是其他安全存储方案。
- 对话请求如何选择模型，以及生图参数放在对话区还是生成模块中。
