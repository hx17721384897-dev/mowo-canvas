# 技能与提示词模板需求

## 目标

把可复用任务能力集中管理，并通过容易理解的提示词模板降低使用门槛。

## 已确认需求

### REQ-SKILL-001 技能入口

第一版主导航包含技能页。该页面用于存放和管理已经编辑好的技能。

验收：用户可以从导航进入技能页，并看到本地技能条目。具体管理操作待确认。

### REQ-SKILL-002 模板关联技能

每个提示词模板应关联一个技能，并定义该任务要求用户填写的输入字段。

验收：选择模板后，界面能明确显示需要填写的内容；发送时保留所选技能与输入数据的关联。

### REQ-SKILL-003 本地优先

第一版技能数据在本机管理，不要求登录、在线市场或海外服务。

验收：技能列表和已保存配置在断网状态下仍可访问。

## 边界

- “技能”不等于 AI 模型，也不保证必须联网执行。
- 电商、社交媒体是用户给出的模板方向示例，完整分类尚未确认。
- 在执行机制未确认前，不把技能描述成已经能够自动完成任务。

## 待确认

- 技能页第一版的创建、编辑、删除、复制、启停范围。
- 技能的数据结构和执行方式。
- 第一批模板、字段和技能映射。
