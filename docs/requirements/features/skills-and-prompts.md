# 技能与提示词模板需求

## 目标

把可复用任务能力集中管理，并为以后由用户自定义提示词模板保留扩展位置。

## 已确认需求

### REQ-SKILL-001 技能入口

第一版主导航包含技能页。该页面用于存放和管理已经编辑好的技能。

验收：用户可以从导航进入技能页，并看到本地技能条目。具体管理操作待确认。

### REQ-SKILL-002 模板能力暂缓

第一版不提供预置提示词模板，也暂不实现模板调用技能。模板的未来入口位置尚未确定。

验收：首页不展示虚构的电商、社交媒体等预置模板；界面不会触发未实现的技能执行。

### REQ-SKILL-003 本地优先

第一版技能数据在本机管理，不要求登录、在线市场或海外服务。

验收：技能列表和已保存配置在断网状态下仍可访问。

## 边界

- “技能”不等于 AI 模型，也不保证必须联网执行。
- 电商、社交媒体等预置分类当前不进入第一版。
- 在执行机制未确认前，不把技能描述成已经能够自动完成任务。

## 待确认

- 技能页第一版的创建、编辑、删除、复制、启停范围。
- 技能的数据结构和执行方式。
- 未来自定义模板的字段和技能映射。
