# 本地视频导入 V01

## 已确认范围

- 从系统文件夹把本地视频拖到画布；或点击底部「插入视频节点」，选中空卡片后通过上方快捷工具「上传视频」选择文件。点击空卡片本身只选中，不打开文件选择窗口；快捷工具提供信息、删除与上传，不显示编辑；导入后提供编辑入口。
- 原片时长超过 5 分钟，或文件超过 500 MiB，先询问「进入视频编辑」或「仍放到画布」。两者都先入库；恰好 300 秒、524288000 字节不触发提示。
- 进入编辑打开已入库原片的观察页；准确逐帧、按帧选段与片段保存已接入，交付前仍需完成大文件及播放边界验收。

## 当前实现与验收

- 首轮容器：MP4、M4V、MOV；浏览器必须能读取对应编码。优先使用 H.264 MP4。WebM、MKV、AVI 和自动转码尚未接入；容器扩展名不代表编码一定可播放。
- 浏览器对不超过 500 MiB 的文件预读媒体时长；更大文件直接展示去向提示，避免大文件因浏览器不支持编码而无法进入接收流程。服务端流式接收文件，显示上传进度并允许取消，再核查容器、视频轨道、尺寸和时长。接收时以磁盘可用空间限制实际字节数；空间不足、取消、损坏或读取失败不产生正式视频资产或新画布节点。
- 成功后保存原片为视频资产并创建视频节点；原文件不压缩。视频默认暂停，点击画面只选中，拖动画面移动节点，不切换播放状态。底部独立控件提供播放、暂停、进度、静音和全屏，操作控件不拖动卡片；离开可视区或浏览器标签页后暂停。
- 节点与资产分离，删除节点保留原片；左侧视频资产展示首帧静态封面与时长，可再次点击或拖回画布。封面在卡片可见时由浏览器读取首帧并缩小绘制，完成后释放临时播放器，不自动播放、不新建资产或修改原片；无法解码时回退视频图标。不将视频 URL 交给图片组件。
- 重复导入相同内容复用资产身份和物理文件；画布可以有多个引用同一资产的节点。
- 普通组可容纳视频，有序图片组不允许视频加入。单次拖入最多 20 个视频，按顺序处理，遇到需要编辑或导入失败时停止余下文件；图片和视频请分开拖入。
- 视频快捷工具使用通用 `NodeQuickToolbar`，继续支持按类型配置工具顺序与文字显示。
- 已入库的原视频卡片显示「导出视频」快捷工具，下载未转码的原文件，沿用资产原始文件名；空卡片不显示导出。导出不创建新资产或画布草稿。

## 本轮边界

当前编辑页提供片段保存与准确逐帧，不提供自动分镜。普通画布原片卡片仍以浏览器播放查看；片段卡片按所选范围控制播放。元数据读取器覆盖常见非分片 MP4/MOV；无法确认时长的特殊容器会提示不支持，不猜测时长。浏览器只预加载元数据，尚未实现完整的素材虚拟化或视频封面缓存。

完整编辑流程与精度要求见[视频编辑页 PRD](video-editor.md#大视频进入编辑页已确认的流程)。5 分钟/500 MiB 是画布放置提示阈值，不是服务端单文件容量上限。
