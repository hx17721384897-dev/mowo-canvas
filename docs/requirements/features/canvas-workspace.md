# 画布工作区需求

## 目标

提供一个以节点和连线组织内容的无限画布，并让项目对话始终可以在右侧继续查看和操作。

## 已确认需求

### REQ-CANVAS-001 工作区布局

项目页以无限画布为主要区域，对话面板固定在右侧。画布顶部设置功能工具区，底部设置常用节点栏。

验收：右侧对话、顶部工具区和底部节点栏不会遮挡彼此的核心操作区域。

### REQ-CANVAS-002 基础画布操作

用户可以平移、缩放、选择和拖动节点，并在节点之间创建连线。

验收：上述操作可通过鼠标完成，且文本输入状态不会误触画布快捷键。

### REQ-CANVAS-003 常用节点栏

底部节点栏直接显示第一版最常用的节点，并提供“加号/更多”入口访问未直接展示的节点。

验收：常用节点可从底栏创建；更多入口能列出其余可用节点。

### REQ-CANVAS-004 右键新增节点

用户在画布空白区域点击右键时，可以打开新增节点菜单。

验收：菜单出现在点击位置附近；选择节点类型后在该位置附近创建节点。

### REQ-CANVAS-005 项目对话

从首页创建项目后，首条用户消息出现在画布右侧对话面板中。该面板后续用于承载项目对话，但第一版无 AI API 时的反馈行为仍待确认。

验收：首条消息属于当前项目，切换项目不会串用对话记录。

### REQ-CANVAS-006 无生成模型

第一版不提供生图、生视频或模型生成节点。界面不能展示会让用户误以为已经可用的生成按钮。

验收：所有可见操作均有真实的本地功能，未来能力只能标为不可用或不展示。

## 节点范围

- 已明确方向：文本节点、图片节点。
- 待确认：裁切是否为独立节点，视频是否进入第一版，以及图片节点需要哪些属性编辑。

## 待确认

- 顶部工具区的第一批按钮。
- 底栏点击后的节点放置方式。
- 右侧对话面板是否可折叠、调整宽度和记忆状态。
