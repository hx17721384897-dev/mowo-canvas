# 视频拆帧需求

状态：2026-11-18 按用户最终讨论更新并接入。设计与验证见[设计书](../../design/video-frame-extraction.md)。

| ID | 已确认行为与验收标准 |
| --- | --- |
| VFE-01 | 新增视频拆帧节点，接受当前项目的原视频或已保存片段，多视频可连接同一节点。视频工具栏提供创建并连接节点的快捷入口。点击开始才提取结果。 |
| VFE-02 | 动画与拍摄视频共用节点，每个输入分别用互斥按钮选择类型。动画识别连续相似画面后按比例还原帧位，保留一拍二、一拍三（如4/6/2在确认整体重复两倍后还原2/3/1）；不直接每段仅留一张。自动依据不足则请求确认目标帧率。拍摄视频不合并相似帧。 |
| VFE-03 | 连接时仅检查大小、时长等输入条件，不读取/检测输出帧数。符合条件可直接点击生成图片组，处理后的序列不超过150张则直接显示现有结果组。动画按节奏还原后的数量判断，拍摄视频按原序列判断。 |
| VFE-04 | 处理结果超过150张则暂停输出，在卡片展示实际数量及三个入口：仅输出前150帧、抽帧、进入编辑页裁剪。抽帧为每N帧保留前K帧（1≤K≤N），即时显示数量，只有不超过150张才能确认抽帧输出；不自动调整间隔或截断。动图原有1000帧限制不变。 |
| VFE-05 | 单个处理范围最多 60 秒、200 MiB，等于上限允许。原片按实际大小判断；片段按片段范围判断，不用整部原片大小拒绝，不把时长比例估算当作准确文件大小。 |
| VFE-06 | 单来源生成与动图相同的有序帧子组，多来源采用现有批次组套子组结构。复用动画帧编辑、详细编辑、保存、动画帧拼接；修改共用 UI 同时影响两类结果。 |
| VFE-07 | 正常间隔抽帧保持覆盖范围时长；因150张上限舍弃尾部时，输出在对应位置结束，不延长最后一张到原片结尾。源时间与编辑时间分别记录，可追溯源帧范围。 |
| VFE-08 | 多来源分别保存类型和处理选择，逐项独立成功、失败或等待确认。待确认结果持久保存，确认后继续原批次，保留已完成子组；重复确认不新增任务或图片草稿。取消清理未提交文件，保留完成结果。明确重新生成才新建批次，不覆盖旧编辑结果。 |

## 首版必需

上述完整流程、源片段校验、取消/失败反馈、参数持久化、来源追溯和原动图回归。

## 交付前收尾

真实动画与拍摄样本验收、150 帧及大小/时长边界验证、批量局部失败与取消清理、刷新恢复、现有编辑/拼接回归、项目规定质量检查。

## 按需增强

镜头移动时单独识别人绘保持、复杂转制节奏恢复、自动恢复中断提取；均不作为首版保证。
