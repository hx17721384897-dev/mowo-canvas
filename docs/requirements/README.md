# 需求文档入口

本目录只承载产品与业务需求，不承载技术实现细节。

## 路由

- 当前产品需求与验收标准：`current-prd.md`
- 尚未确认、会影响设计的问题：`open-questions.md`
- 产品统一术语：`../../GLOSSARY.md`
- 某项功能需要独立说明时，在 `features/` 创建一个文件，并从当前 PRD 链接。

## 沉淀规则

1. 只把用户明确确认的内容写成正式需求。
2. 推测、候选方案和信息缺口进入开放问题。
3. 每项可实现需求使用稳定 ID，并给出可观察的验收标准。
4. 技术方案写入架构或设计文档，不混进 PRD。
5. 当前需求改变时直接更新当前文档；历史只在用户明确需要时归档。
6. 完成需求后保留它作为当前产品行为，除非产品行为已经被替换。
