# MOWO Canvas 当前 PRD

## 产品目标

提供一个可在 Windows 本机运行、以无限画布为核心的模块化个人效率工作台。用户可以独立使用功能模块，也可以连接兼容模块形成工作流；产品先满足单人自用，再为未来中国大陆线上部署保留迁移边界。

## 当前用户

单个本地用户。当前不需要账户、注册、团队或公网访问。

## 第一版核心体验

1. 首页是画布项目中心，主体展示历史画布和“新建画布”入口，不设置 ChatGPT 式大型对话框。
2. 点击历史画布进入对应项目；点击“新建画布”创建空白项目并进入工作流编辑器。
3. 工作流编辑器与首页使用不同侧栏：左侧为完整工具库，顶部为项目级工具栏，底部为常用工具快捷栏，右侧为当前项目对话。
4. 用户可以通过左侧工具库、底部常用工具栏、画布空白处右键和双击画布创建模块。
5. 用户离开后，可以从首页历史画布重新打开项目，并恢复原有工作流与对话。
6. 第一版右侧对话区只建立界面结构，不调用语言模型、生图模型或自动生成内容。
7. 模块可以独立工作；只有需要交换内容或表达处理顺序的模块才提供连接能力。
8. 输入端口位于模块左侧、输出端口位于右侧；模块可以具有多个具名端口，端口可以按功能接收单条或多条连接。
9. 裁切模块的完整目标是把一个或多个规则图集批量拆分为图片集合，结果可按横向或纵向顺序排列，并支持单张缩放、移动以及“仅当前/应用全部”的调整范围；首个原型只制作卡片外壳、左右端口和按钮区域。
10. 功能模块需要保留统一扩展边界，后续新增模块不应要求重写画布核心。
11. 设置区域预留语言模型与生图模型的 API 管理能力；未来生图结果直接成为当前画布的图片模块。
12. 编辑器使用紧凑的字体与控件密度，优先保证中央画布面积；左侧工具库和右侧对话面板都支持折叠。

## 第一版明确不做

- 不接入 AI 生图、AI 视频或其他生成模型。
- 暂不接入 DeepSeek 或其他在线 AI API；“生成”节点只保留节点形态，不能假装已有真实生成能力。
- 第一批预置提示词模板暂不制作。
- 不实现注册、登录、账户、团队、多人协作、付费或云端部署。
- 不照搬参考产品中的素材库、个人主页、积分、分享等未确认功能。

## 工程基线

- 使用已建立的 Next.js、TypeScript 与 npm 工程基线。
- 画布阶段使用 React Flow；数据持久化在原型确认后引入 SQLite 与 ORM。
- 秘密不得写入前端代码或 Git，具体规则以工程和安全文档为准。
