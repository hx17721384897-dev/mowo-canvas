# MOWO Canvas 当前 PRD

## 产品目标

提供一个可在 Windows 本机运行、以无限画布为核心的模块化个人效率工作台。用户可以独立使用功能模块，也可以连接兼容模块形成工作流；产品先满足单人自用，再为未来中国大陆线上部署保留迁移边界。

## 当前用户

单个本地用户。当前不需要账户、注册、团队或公网访问。

## 第一版核心体验

1. 用户可以在首页输入内容并发送，也可以点击右上角“新建画布”。
2. 两种入口都会创建一个项目，并进入该项目的无限画布；对话入口带有页面过渡。
3. 画布右侧保留项目对话；用户可以在主体区域创建节点、连接节点并组织工作流。
4. 第一版发送消息只要求完成创建和跳转，不要求 AI 回复或自动生成内容。
5. 用户离开后，可以从左侧最近项目或项目列表重新打开，并恢复原有工作流与对话。
6. 用户可以通过底部常用模块栏、画布空白处右键和双击画布三种方式创建模块。
7. 模块可以独立工作；只有需要交换内容或表达处理顺序的模块才提供连接能力。

## 产品模块

- 首页与导航：`features/home-and-navigation.md`
- 项目创建、保存与恢复：`features/project-lifecycle.md`
- 无限画布工作区：`features/canvas-workspace.md`
- 技能与提示词模板：`features/skills-and-prompts.md`
- 核心术语：`../../GLOSSARY.md`

## 第一版明确不做

- 不接入 AI 生图、AI 视频或其他生成模型。
- 暂不接入 DeepSeek 或其他在线 AI API；“生成”节点只保留节点形态，不能假装已有真实生成能力。
- 第一批预置提示词模板暂不制作，只为以后自定义新增预留位置。
- 不实现注册、登录、账户、团队、多人协作、付费或云端部署。
- 不照搬参考产品中的素材库、个人主页、积分、分享等未确认功能。

## 工程基线

- 使用已建立的 Next.js、TypeScript 与 npm 工程基线。
- 画布阶段使用 React Flow；数据持久化在原型确认后引入 SQLite 与 ORM。
- 秘密不得写入前端代码或 Git，具体规则以工程和安全文档为准。
