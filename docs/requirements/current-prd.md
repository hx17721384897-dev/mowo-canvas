# MOWO Canvas 当前 PRD

## 产品目标

提供一个可在 Windows 本机运行的节点与连线型无限画布，先满足单人自用，再为未来中国大陆线上部署保留迁移边界。

## 当前用户

单个本地用户。当前不需要账户、注册、团队或公网访问。

## 当前迭代：工程准备

### REQ-ENV-001 可重复安装

项目必须使用锁文件安装依赖，并明确 Node.js 与 npm 基线。

验收：全新环境可以执行 `npm ci`；版本约束可以从仓库文件中找到。

### REQ-ENV-002 本地运行

项目必须能够通过本地命令启动，并只以本地开发为当前目标。

验收：`npm run dev` 可以启动应用；打开根页面能看到 MOWO Canvas 工程就绪信息。

### REQ-ENV-003 工程质量检查

项目必须提供统一命令检查代码规范、类型和生产构建。

验收：`npm run check` 能依次执行 ESLint、Next.js 路由类型生成、TypeScript 和生产构建。

### REQ-DOC-001 按需文档

AI 必须先读取当前状态，再根据任务只读取必要的需求、API、设计或工程文档。

验收：项目 Skill 中存在明确路由，默认不读取归档历史。

### REQ-SEC-001 秘密隔离

秘密不得进入前端代码或 Git；公开变量与服务端秘密必须有明确边界。

验收：仓库忽略实际环境变量文件，并提供不含真实值的 `.env.example`。

## 后续已确认方向

- 阶段 1 将实现 React Flow 节点画布原型。
- 阶段 2 再引入 SQLite、ORM、本地素材和可靠保存。
- 当前不实现 AI 生成、账户、付费、多人协作或云部署。

更完整的范围边界见 `../02-product-scope.md`，迭代顺序见 `../03-roadmap.md`。
