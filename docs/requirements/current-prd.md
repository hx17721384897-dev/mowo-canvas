# MOWO Canvas 当前 PRD

## 产品目标

提供一个可在 Windows 本机运行的节点与连线型无限画布，先满足单人自用，再为未来中国大陆线上部署保留迁移边界。

## 当前用户

单个本地用户。当前不需要账户、注册、团队或公网访问。

## 第一版核心体验

1. 用户在首页输入任务，或先选择一个提示词模板并填写所需内容。
2. 用户发送第一条消息后，系统自动创建一个项目，并通过过渡动画进入该项目的无限画布。
3. 画布右侧保留项目对话；用户可以在主体区域创建节点、连接节点并组织工作流。
4. 用户离开后，可以从左侧最近项目或项目列表重新打开，并恢复原有工作流与对话。

- 核心术语：`../../GLOSSARY.md`

## 第一版明确不做

- 不接入 AI 生图、AI 视频或其他生成模型。
- 暂不接入 DeepSeek 或其他在线 AI API；接口位置可以预留，但不能假装已有真实 AI 能力。
- 不实现注册、登录、账户、团队、多人协作、付费或云端部署。
- 不照搬参考产品中的素材库、个人主页、积分、分享等未确认功能。

## 工程基线

- 使用已建立的 Next.js、TypeScript 与 npm 工程基线。
- 画布阶段使用 React Flow；数据持久化在原型确认后引入 SQLite 与 ORM。
- 秘密不得写入前端代码或 Git，具体规则以工程和安全文档为准。
