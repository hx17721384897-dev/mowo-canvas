# 安全与备份

## 当前风险重点

本地阶段最重要的不是公网攻击，而是误删除、磁盘损坏、程序升级覆盖数据和导入异常文件。

## 数据保护

- 源代码与运行数据分离。
- 自动备份不得覆盖唯一一份旧备份。
- 备份至少包含 SQLite 数据库、素材目录和数据版本信息。
- 恢复流程必须经过实际验证。
- 导入 JSON 前验证结构、版本和大小。
- 文件上传验证扩展名、MIME、大小和保存路径。
- 所有文件路径必须限制在预期数据目录内，防止路径穿越。

## 建议的备份层级

- 自动轮换备份：用于日常误操作恢复。
- 手动里程碑备份：用于大版本升级前恢复。
- 独立介质副本：防止电脑或磁盘整体损坏。

## 代码安全

- 密钥只进入本地环境变量。
- 依赖升级单独审查并运行构建测试。
- 不执行来源不明模板中的安装脚本。
- 上线前重新进行认证、授权、上传和接口安全审查。
