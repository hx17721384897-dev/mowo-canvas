# 迭代路线

路线按能力门槛推进，不使用未经验证的固定工期。每个阶段完成后形成 Git 检查点，再进入下一阶段。

## 当前视频下载迭代

A—D 已完成下载、确认入库、兼容预览和交付收尾；下一步进行用户体验验收，再衔接视频编辑流程。实际证据见[实施进度](design/video-download-progress.md)。

视频编辑在观察与分镜之后，按[视频片段剪辑设计书](design/video-cutting-design.md#实施进度目标)的五步推进：页面骨架与定位、双时间坐标、剪辑操作、编辑历史与保存、结果交付。画面裁切与构图在剪辑完成后进入下一阶段。已确认交互见[视频编辑 PRD](requirements/features/video-editor.md#视频片段剪辑分阶段实施中)。

2026-11-12 已确认收缩首版，复用已验证的引擎、登录、媒体与进程管理，按“最小任务数据与接口 → 可操作下载弹窗 → 确认入库与预览 → 单执行者交付收尾”推进。多协调器租约、完整崩溃恢复、删除隔离和在线备份不作为本轮前置条件。范围与检查点以[下载设计书](design/video-download-v01.md)为准，未来增强记录在[后续清单](design/video-download-backlog.md)。

## 阶段 0：文档与治理

完成标准：

- 文档入口、任务路由和当前状态清晰。
- 当前事实与历史记录隔离。
- 项目级 Skill 可指导后续 AI 工作。
- Git 可以提供干净检查点。

## 阶段 1：最小画布原型

- 创建 Next.js、TypeScript、Tailwind 项目。
- 建立以历史画布和“新建画布”为核心的首页项目中心。
- 接入 React Flow。
- 建立编辑器左侧完整工具库、顶部项目工具栏、底部常用工具栏和右侧对话区的结构。
- 建立插入、裁切、生成三个底部一级入口。
- 插入菜单可以创建文本、图片、视频节点；裁切和生成先创建卡片外观。
- 实现拖动、缩放、连线、删除和复制。
- 使用浏览器存储验证保存与恢复。
- 支持画布 JSON 导入、导出。

完成标准：首页可以创建画布，核心画布交互可用，刷新页面可以恢复；不要求 AI 回复、真实裁切或模型生成。

## 阶段 2：可靠的本地应用

- 引入 SQLite 与选定 ORM。
- 建立项目、画布文档和素材记录。
- 素材保存到本地数据目录。
- 实现防抖自动保存、保存状态和错误恢复。
- 实现撤销、重做、搜索、备份与恢复。

完成标准：可以长期自用，更新程序不会破坏用户数据。

## 阶段 3：产品体验完善

- 优化节点编辑、快捷键、上下文菜单和大画布性能。
- 增加数据迁移、异常恢复和测试。
- 完善安装、升级和本地启动体验。

完成标准：功能与数据模型稳定，可以评估对外测试。

## 阶段 4：上线准备

上线准备前优先推进本地 AI 接入。V1 待完成的设置与存储、V2 生图入画布及后续引用、搜索和 Skill 的进入条件见 [AI 长期路线](ai/agent-implementation-plan.md)。

- 引入账户和权限。
- SQLite 迁移到 PostgreSQL。
- 本地素材迁移到国内对象存储。
- 增加生产安全、日志和备份。
- 使用国内服务器、域名和 HTTPS。
- 按实际业务办理备案与合规手续。

## 阶段 5：可选扩展

团队协作、收费系统和更复杂的素材处理根据真实需求评估。语言模型与图像模型接入已纳入上线准备前的本地迭代。
