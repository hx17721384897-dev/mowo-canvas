# 迭代路线

路线按能力门槛推进，不使用未经验证的固定工期。每个阶段完成后形成 Git 检查点，再进入下一阶段。

## 阶段 0：文档与治理

完成标准：

- 文档入口、任务路由和当前状态清晰。
- 当前事实与历史记录隔离。
- 项目级 Skill 可指导后续 AI 工作。
- Git 可以提供干净检查点。

## 阶段 1：最小画布原型

- 创建 Next.js、TypeScript、Tailwind 项目。
- 建立首页对话创建、右上角直接新建和进入画布的两条路径。
- 接入 React Flow。
- 建立插入、裁切、生成三个底部一级入口。
- 插入菜单可以创建文本、图片、视频节点；裁切和生成先创建卡片外观。
- 实现拖动、缩放、连线、删除和复制。
- 使用浏览器存储验证保存与恢复。
- 支持画布 JSON 导入、导出。

完成标准：首页可以创建画布，核心画布交互可用，刷新页面可以恢复；不要求 AI 回复、真实裁切或模型生成。

## 阶段 2：可靠的本地应用

- 引入 SQLite 与选定 ORM。
- 建立项目、画布文档和素材记录。
- 素材保存到本地数据目录。
- 实现防抖自动保存、保存状态和错误恢复。
- 实现撤销、重做、搜索、备份与恢复。

完成标准：可以长期自用，更新程序不会破坏用户数据。

## 阶段 3：产品体验完善

- 优化节点编辑、快捷键、上下文菜单和大画布性能。
- 增加数据迁移、异常恢复和测试。
- 完善安装、升级和本地启动体验。

完成标准：功能与数据模型稳定，可以评估对外测试。

## 阶段 4：上线准备

- 引入账户和权限。
- SQLite 迁移到 PostgreSQL。
- 本地素材迁移到国内对象存储。
- 增加生产安全、日志和备份。
- 使用国内服务器、域名和 HTTPS。
- 按实际业务办理备案与合规手续。

## 阶段 5：可选扩展

根据真实用户需求评估团队协作、AI 能力、收费系统和更复杂的素材处理。未确认前不进入主线设计。
