## V2 图像生成与入画布

- 首版接一个图像供应商，从文字提示词生成图片。设置独立管理语言模型与图像模型。生成前说明参数与费用。参考图随 V3 和供应商能力另行确认。
- 计划在本地后台执行路径上实现持久任务。提交前保存请求标识和输入摘要，取得供应商任务 ID 后立即保存。刷新或重启后依据租约和已有任务核对状态。供应商可能接单但本地没有收到 ID 时，按幂等键或查询能力核对；无法核对则显示状态未知，由用户核实并决定是否重新付费提交。
- 下载并验证原始结果后通过现有资产模块去重入库。保留提示词、模型版本、参数和任务到输出的关联，预览单独管理。画布关闭时保留待放置结果。参考资产与输入派生关系在 V3 扩展。
- 验收覆盖单张与多张、部分下载失败、执行器退出和重启、过期租约、重复领取、提交响应丢失、下载入库中断、重复回调与重复放置。

## V3 画布素材引用

- 用 @ 搜索当前画布素材并显示可移除的引用标签。使用稳定资产、集合或节点 ID，区分同一素材的多个节点位置。素材移走或缺失后仍能辨认历史引用，缺失要有提示。
- 服务端核对当前项目权限。发送前让用户查看实际外发的文字、元数据和处理后的图片；保存相同的输入快照，记录素材版本、处理结果和参数。只有具备视觉能力的模型接收真实图像。视频内容理解另行设计。
- 实施前确认集合、多选、单张及累计字节和像素限制，采用应用与供应商两者中更严格的上限。转换使用副本，原素材保持原样；超限给出原因。
- 验收覆盖搜索定位、同资产多实例、限制提示，以及界面展示与实际外发内容一致。

## V4 联网搜索

- 由用户明确开启本次搜索。后端控制调用次数、超时和结果长度；引用能追溯到真实的工具结果。保留标题、链接、摘要与获取时间。网页正文读取是单独能力，使用的页面和摘录在工具结果中可见。
- 选择供应商时验证可达性、费用、稳定性和中文结果。验收覆盖成功、无结果、超时、限额及来源对应。

## V5 Skill 与画布工具

- Skill 包含稳定 ID、名称、用途、版本、操作说明和允许调用的工具。首版由用户显式选择，运行记录版本。首个实际操作场景待定。
- 工具登记参数、限制、返回结果、错误与副作用。记录稳定操作 ID，重试复用已完成结果。限定运行时长、步骤与调用次数；停止后不再调度新步骤，已经发送的远程任务遵守供应商规则。删除、覆盖或付费操作的确认条件随工具设计。
- 验收覆盖一个明确流程、失败与重试、执行期间用户继续编辑，以及输入与结果的可追溯性。按场景区分任务完成、草稿可审核、正式资产保存、节点放置和画布保存确认。

## V2 与 V5 共用的画布交付门槛

以下为后续实施约束。服务端保存结果和待应用操作，浏览器基于最新画布应用增量，通过现有撤销和串行保存链确认完成。

- 记录项目和运行 ID、稳定操作及节点 ID、操作类型、输入输出引用和载荷版本。区分待应用、已应用待保存、已保存和失败。
- 按操作与节点 ID 防止重复放置，一次操作对应一次撤销。撤销意图持久保留，恢复时不能再次放置。应用或回执丢失时先核对已保存画布，关闭画布或失败时保留待应用结果。
- 新增节点可并入最新画布。修改、删除或替换已有节点需要前置条件，变化后提示冲突。实施需支持服务端验证的单活动编辑器约束，或达到同等保护的版本冲突检查。自动应用发布前验证双标签、双窗口、断线、接管及旧编辑器拒写。
- 发布前覆盖用户继续编辑、离开画布、重复投递、保存失败、回执丢失和撤销后恢复。API 与迁移设计在相应任务启动后具体化。
