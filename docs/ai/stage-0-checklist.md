# 阶段 0 执行与分工

更新于 2026-11-05。当前处于工程准备，完整验收仍待真实调用与独立执行器验证。

## 用户负责

1. 在 [DeepSeek 开放平台](https://platform.deepseek.com/)注册并登录，按平台当时提示完成必要认证。
2. 查看 API 余额与官方计费说明，自行决定测试充值金额并完成支付。网页聊天订阅或使用情况不能作为 API 余额依据。
3. 创建专用于 MOWO 本地测试的 API Key，保留在自己的安全位置。聊天中只反馈账号、余额、Key 是否准备好。
4. 开发阶段在项目根目录的 .env.local 中填写 DEEPSEEK_API_KEY。该文件应被 Git 忽略，不能使用 NEXT_PUBLIC_ 前缀。正式设置界面随后替代开发配置。
5. 真实调用会产生供应商费用，用户准备好后在本机执行下方的一次性测试，或明确授权开发验证。后续由用户验收侧栏体验。

## 开发负责

- 整理官方接口、安装依赖兼容验证、固定版本、数据库与接口设计。
- 构建独立执行器、会话保存、停止、重试和断线恢复，完成模拟测试。
- 实现设置和侧栏，保护密钥，提供分类错误。
- 准备一次性连接检查，真实调用后核对结果，记录验证状态。
- 每个已完成的文档核对后 Git 存档。

## 本机检查

项目根目录运行 node --env-file-if-exists=.env.local scripts/check-deepseek.mjs，只检查密钥是否存在，不输出密钥。

用户准备好后运行 node --env-file-if-exists=.env.local scripts/check-deepseek.mjs --live，发起一次固定短文本请求。该测试只验证基本调用与鉴权，不能替代流式、停止或后台执行验收。脚本不自动重试。
