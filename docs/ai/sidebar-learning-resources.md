# Agent 侧栏学习资料

检索日期为 2026-11-05。以下为学习与选型候选，尚未决定项目依赖。

## 开源项目与官方教程

- [CopilotKit 仓库](https://github.com/CopilotKit/CopilotKit)、[官方快速开始](https://docs.copilotkit.ai/quickstart)、[侧栏组件](https://docs.copilotkit.ai/reference/v2/components/CopilotSidebar)。重点学习应用内侧栏、上下文和工具执行的关系，接入前核实当前版本与模型适配方式。
- [assistant-ui 仓库](https://github.com/assistant-ui/assistant-ui)、[安装教程](https://www.assistant-ui.com/docs/installation)。重点学习消息、输入框、流式输出和工具结果的界面表达。
- [AI SDK 的 DeepSeek 适配文档](https://ai-sdk.dev/providers/ai-sdk-providers/deepseek)。用于学习语言模型调用层，可作为侧栏界面的配套资料。

## 视频

[GreatStack 的 Next.js 与 DeepSeek API 教程](https://www.youtube.com/watch?v=uJPa_18Zf1I)，发布于 2025-03-17。可学习聊天请求与响应流程。教程还使用 Clerk、MongoDB Atlas 和 Vercel，其账户、数据库和托管选择需要按本项目本地方案调整。该视频是聊天应用教程，画布工具调用需要另行设计。
