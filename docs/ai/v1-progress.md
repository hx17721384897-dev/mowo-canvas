# V1 基础对话实施进度

更新：2026-11-06。唯一产品方案仍是 [实施计划](agent-implementation-plan.md)，本文记录实现证据，不是另一份计划或原型草稿。

## 本轮已完成

- 正式 SQLite 迁移新增运行、消息和有序事件表。对话按当前项目隔离；删除项目时级联清除对话，不修改画布保存流程。
- 创建、恢复查询、历史读取、SSE 快照/事件重放和独立停止接口，契约见 [AI 运行接口](../api/ai-runs.md)。
- 独立 Node 工作进程使用 AI SDK + DeepSeek，服务端环境变量传递密钥，禁止将密钥写入 SQLite、命令行参数或日志。
- SQLite 原子幂等、单画布并发限制、带有效期的执行租约和写入隔离，停止与成功竞争同一终态。
- 过期运行保留部分回复并标记中断，不自动重新付费提交。尚未领取的任务在下一次 AI 请求时恢复调度。
- 右侧助手在原有可调整宽度、可折叠的外壳中启用，使用 assistant-ui 外部状态运行时；支持文字发送、SSE 流式回复、独立停止、复制、失败后重新生成及按画布恢复历史。当前只发送文字，界面说明上下文截取范围。
- 发送前将请求标识与消息暂存本机浏览器，响应未知时阻止新发送，先按原标识核对；只有查询确认未收到且用户点击重试时，才沿用原标识提交。不因刷新自动创建新的付费请求。
- 配置状态接口仅返回是否检测到服务端 Key；设置按钮当前打开配置说明窗口，不显示 Key，不执行付费连接检查，暂不提供模型切换或密钥写入。
