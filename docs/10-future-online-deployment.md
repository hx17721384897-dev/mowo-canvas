# 未来线上部署

本文件描述迁移方向，不授权当前阶段采购、部署或开放任何线上服务。

## 目标形态

```text
浏览器
  ↓ HTTPS
国内 Nginx / 负载入口
  ↓
Next.js 应用
  ├── PostgreSQL
  ├── 国内对象存储
  └── 按需增加后台任务与缓存
```

## 迁移顺序

1. 稳定数据模型并建立 SQLite 迁移测试。
2. 引入账户和项目归属。
3. 将 SQLite 数据迁移到 PostgreSQL。
4. 将本地素材迁移到国内对象存储。
5. 增加生产环境日志、监控、备份和恢复演练。
6. 选择中国大陆云服务器并配置域名、HTTPS。
7. 按实际主体和业务办理备案、许可及其他合规事项。
8. 小范围测试后再扩大访问。

## 约束

- 优先使用中国大陆可稳定访问和支持自托管的基础设施。
- 不把核心运行能力绑定在海外托管平台。
- 是否加入 CDN、Redis、任务队列或多实例，以真实负载为依据。
- 收费、AI 服务、用户内容发布等业务上线前单独进行合规评估。
